# 导演投影的业务装配

本目录负责把保存的小说业务事实转为新导演纯投影的输入，不拥有生成算法、编排状态机或恢复命令。

- `confirmationRoutes.ts`：用本书实际资产身份定位新导演审阅地址。
- `productionProgress.ts`：核验固定作业的 Run/书/范围归属，读取实际当前章和结构化阶段；章节完成数量复用生产模块的当前内容闭合策略。
- `recoveryCandidates.ts`：提供返回来源页的恢复候选，不在列表执行恢复。

领域投影不访问数据库或具体生产服务。应用层通过 bootstrap 端口接受业务事实；当前章不能从展示标签、阅读选中章或完成数量猜测。轮询读取不改变控制版本、问题游标或正文。章节进度和规划台账使用不同单位，不能把编排十步显示为十章。

后续范围只用于用户核对授权，必须在遇到已有正文时停止，不能自动续跑或修改旧合同。暂停与待确认按保存的控制态呈现，不因读到旧运行阶段而解除。参见 [导演确认与恢复边界](../../../../../docs/wiki/workflows/director-next-assisted-gates.md)。
