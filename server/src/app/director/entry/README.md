# 导演入口归属

应用装配层拥有新旧入口的切换，导演领域和步骤适配器不依赖旧编排器。

`agentTools.ts` 保留 V1 Runtime 工具，通过注册表稳定包装检查本书版本及任务 epoch。缓存定义也不能调用其他版本或旧代次的服务；`CONFLICT` 不进入自动重试。工具注册不是执行授权。

来源导航只读取旧任务的小说归属，不读取旧 Seed、不协调旧 Runtime、不追加旧命令。没有小说归属的开书任务返回开书页。恢复和正文范围选择由小说导演台承担，Agent 不把旧参数转译成新的执行授权。

注册表边界与应用单例装配一致，由 `createApp` 安装按小说归属的守卫。V2 可用开关不改变 V1 小说或任务的身份，关闭它也不能将 V2 小说交给 V1。

列表、详情和创建响应按持久化版本统一投影 `workspaceSourceRoute`；V1 和短篇返回空 V2 来源。前端只接受与本书 ID 及版本匹配的地址。该导航元数据不授权生成，显示偏好不能覆盖版本归属。

编辑页接管入口先复用小说详情查询。V2 来源只导航；V1 身份和空 V2 来源才允许加载原接管界面。未知、错误或不匹配的来源只提供重新读取，不能用旧界面兜底。详情缓存暂缺来源时也不能提前加载旧接管查询。

旧工作流的书级 auto-director、current 和 book-automation 对 V1 保留原行为；对 V2 返回空当前态及 V2 来源，不进入旧投影。V2 当前态仅包含当前 epoch 的 Run。历史记录和开书准备只读详情保持独立。完整规则见 [导演版本隔离](../../../../../docs/wiki/workflows/director-version-isolation.md)。
