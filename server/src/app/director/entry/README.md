# 导演入口切换

应用装配层拥有新旧入口的切换，导演领域和步骤适配器不依赖旧编排器。

`agentTools.ts` 在新导演启用时从工具目录和 AI 规划上下文排除旧 Runtime 工具，并通过 Agent 工具注册表的稳定执行包装阻止历史计划或提前缓存的定义调用旧服务。只隐藏工具不足以保护已保存计划，因此执行时仍检查当前应用边界；`CONFLICT` 不进入自动重试。

来源导航只读取旧任务的小说归属，不读取旧 Seed、不协调旧 Runtime、不追加旧命令。没有小说归属的开书任务返回开书页。恢复和正文范围选择由小说导演台承担，Agent 不把旧参数转译成新的执行授权。

注册表边界与应用内其他单例装配一致：一个服务进程使用一个入口策略。`createApp` 在每次创建时设置或清除边界，关闭新导演时保留既有工具行为。

小说入口策略由 `createApp` 挂载小说路由时捕获，并传给 HTTP 投影的 `res.locals.directorNextEnabled`。列表、详情和创建响应统一为长篇返回 `workspaceSourceRoute`，短篇或未启用新导演返回空值；它是导航元数据，不传入创建服务、不写入数据库的创作方式，也不授权生成。前端只接受与当前小说 ID 完全匹配的新来源地址，不能用旧任务进度或创作方式覆盖它。

编辑页接管入口先复用小说详情查询。新来源只导航；明确为空才允许加载关闭开关时的旧接管界面。未知、错误或不匹配的来源只提供重新读取，不能用旧界面兜底。详情缓存暂缺来源时也不能提前加载旧接管查询。
