# 导演工作台保存资料投影

## 责任与来源

`../workspace.ts` 是工作台读取入口，本目录通过 `index.ts` 提供世界与角色的资料投影。共享展示契约位于 `shared/types/director/workspace.ts`，不得把展示字段写入导演控制状态或生成任务。

- 世界优先读取本书 `NovelWorld` 副本，副本不存在才兼容读取关联 `World`；副本缺字段或损坏不从外部样本补齐。
- 完整结构仅做现有世界归一化，不重新生成、不截取前几个条目。保存的使用范围必须通过结构校验，并核对小说与世界归属。
- 故事约定和角色动机来自保存字段；不从简介或正文推断设定。世界规则与角色变化的生成仍由既有生产模块负责。

## 禁止副作用

读取不能调用 `ensureFromLegacyNovel`、`getNovelWorldView` 或 `WorldContextGateway.getWorldContextBlock`，它们可能初始化本书副本或构建切片。资料页轮询必须只读，不能产生 AI 用量、世界同步或小说正文修改。损坏字段以读取警告呈现，不冒充有效的空世界。

测试以独立临时库比较读取前后的保存行，覆盖本书副本与外部样本分歧、无外部绑定的本书世界、旧数据兼容和跨书范围拒绝。
