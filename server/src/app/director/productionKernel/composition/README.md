# V2 长篇原生装配

`productionComposition` 的 chapter_batch 经持久实现绑定进入本目录。开关默认关闭；旧作业保持 legacy，已绑定的新作业不随开关改变实现。不创建替代的 GenerationJob。

runtime 捕获当前 worker、运行契约、完整问题策略与模型配置。每个原生 Chat 请求核对书归属、租约、当前单章版本/领取、完整正文和冻结模型配置；实际用量由独立物理账本记账。正式正文与审校终态通过内核事务生命周期入口发布。

preparation 复用非冻结合同/章规划的已批准准备端口。contexts 保留原生平台合同、writer sanitization 和 context broker。stages 复用原生 writer、接收与安全补丁；reconciliation 安装统一抽取、人物身份、十类消费者、完整规范版本、时间线和条件全量伏笔对账。

人物确认的原生 callback 事务绑定到当前事务。待确认错误在事务提交后传播，保留来源页可处理的记录；运行、单章领取和完整正文检查不能由旧服务较宽的守卫代替。辅助模式的未确认记录会阻止显式恢复，自动模式的非阻塞延迟身份保持原行为。

用户已批准 RAG HTTP/只读索引接口及伏笔账本只读范围。preparation 安装 `rag` 的持久检索执行范围，按应用显式检索设置执行，用户关闭时跳过可选知识库召回，书内直接上下文仍保留；实际 embedding/重排重试及拆分均保存独立请求与额度。集合与索引检查只读，缺失时返回知识库来源页。空账本读取不触发隐式模型同步，正式回填继续由 reconciliation 发布。未登记的原生 Chat/RAG 请求仍锁存拒绝。

当前入口联测使用全新 SQLite、已保存可复用的合同和章规划、原生 PromptRunner/审校/消费者，以及明确 SDK/HTTP 传输替身。开启 RAG、空账本的场景完成 approved/completed，重启并关闭开关后读取完成结果不重复调用或报告。2026-10-26 真实页面在用户批准关闭检索后完成原运行首章、终态和重启去重，规则映射审查待审为0。该结果不代替检索开启的真实提供方场景。输出额度在描述/执行/恢复期间冻结到相同任务范围；新任务使用用户配置（缺省8192），已有单元保留其阶段额度，不因默认值调整扩大权限。
