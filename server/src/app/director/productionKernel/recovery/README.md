# 来源页恢复与取消

`commands.ts` 仅由 `savedContent` 的显式命令调用，并参与导演命令仓储已有事务。读取与运行记录投影不会执行这里的动作。

质量暂停确认锁定书 epoch、运行控制和当前完整正文，使用领域动作及 ProductionUnitRun 版本 CAS；不改变策略或制品。未知请求仍保留原领取，恢复不能将其清空后重发。取消只结束本次运行控制，即使书 epoch 已被替换也允许取消旧任务，不影响新任务或已有正文。

预算拒绝保存具体物理请求的未发送额度。来源页只读投影该记录和最新用量；追加额度校验章节、计量口径、旧限额及下一步所需额度。拒绝记录解除、授权事件、命令幂等记录和控制恢复同事务提交。兼容字段 `jobId` 使用真实 ProductionUnitRun ID，不创建 GenerationJob。

授权事件不改写冻结运行契约。单章授权优先，后续章节授权作为未单独授权章节的默认额度；重启通过事件恢复。实际请求仍需新 worker 的租约及版本权限，授权事件本身不能恢复旧执行者的权限。完整生产入口装配和全局重规划恢复仍需独立验收。
