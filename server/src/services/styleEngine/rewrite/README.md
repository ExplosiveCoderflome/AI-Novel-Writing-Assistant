# 表达补丁保护

本模块拥有表达补丁的原文身份、问题许可、修改范围与明确词项保护，不判断风格、不写章节、不控制导演。

外部通过 `index.ts` 消费。规则/AI 权限先由诊断合同确认，补丁必须关联真实可修问题。数值和显式专名只作为纯表达补丁的安全锚点；有问题依据的事实纠错交由已有候选验收核对，不能把错误原稿当正史。

词项一致不能证明事实一致。返回的 `semantic_facts=not_checked` 必须保留；自动候选通过既有 AI 复验后才能升级，手动粘贴稿维持原文保护预览。拒绝候选保留原稿、不返还自动处理额度，也不另开重试。

`style-patch-v1` 的整章触及 30%、新增 5%、篇幅变化 30% 是保守工程初值；不足 500 字的选区采用触及 100%、新增 20%。它们尚未经过真实语料校准，不代表编辑质量达标。
