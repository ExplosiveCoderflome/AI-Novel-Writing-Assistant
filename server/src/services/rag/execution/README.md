# 检索执行端口

本模块只拥有请求描述、执行范围及只读保护，不决定检索、重排或索引生产策略。

没有安装范围时，embedding、重排及检索仍执行既有路径。安装范围后，AsyncLocalStorage 为每个异步调用链隔离 retrieve/request 端口；并发的旧调用与其他运行不会借用端口。实际 HTTP 的完整输入、模型、配置摘要和重试序号交给调用方登记，响应仅保留原生解析与用量所需字段。

范围内的保护失败会锁存。下层兼容逻辑即使捕获异常并返回空结果，范围结束时仍失败，避免预算或失权错误变成可发布上下文。索引只读检查同样参与保护；集合或索引不满足要求时返回 RagIndexUnavailableError 和知识库来源页。

调用方负责持久领取、预算、来源与所有权围栏；原生检索服务继续负责词法融合、排序、章节衰减、HTTP 重试与拆分。正式索引创建仍由原显式索引流程执行。
