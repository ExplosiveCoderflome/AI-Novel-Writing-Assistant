# V2 章节事实检索

## 职责

通过小说资产模块的读投影，复用统一抽取的摘要与具体事实，生成现有 `chapter_summary` 文档的独立分块。原文和事实分块携带来源章与正文 hash，不建立新的事实表或检索所有者类型。

`loadVersionedChapterSummaryDocuments` 返回 null 时才使用 V1 的摘要来源；V2 无有效当前结果时返回空文档，非法结果使已有索引作业失败。摘要值必须与当前成功检查点一致，不能把旧摘要贴到新正文版本上。

`filterCurrentArtifactChunks` 在混合检索融合前校验带 V2 标记的正文及摘要块，排除本书之外、正文版本失效、当前章和未来章。过滤保持候选对象身份，避免同 ID 的另一来源结果绕过版本校验。未带版本标记的旧索引不在该保护范围内。

## 成本与依赖

RAG 只消费小说模块的结构化读投影，不触发抽取、提案确认或导演运行。结构化摘要/事实块使用来源章节说明，不为每块调用上下文模型；正文与普通资料保持既有增强策略。向量化继续由现有异步索引作业拥有，失败不阻断已保存章节。

外部模块通过 `index.ts` 使用加载器与过滤器。维护时同时检查既有 V1 来源、当前版本筛选和“逐事实分块不增加模型调用”的测试。
