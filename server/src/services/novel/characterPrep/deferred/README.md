# 导演 V2 角色延后补全

本目录负责 V2 的可选角色补全调度和安全写入。领域内核、正文生产和最终资源回填继续由各自模块负责。

- `scheduleAfterPipeline` 只接受成功结束、属于当前 V2 代次的正文作业；最终正文已跨过资源回填边界后才能入队。依据 V2 运行合同，禁止读取 V1 任务 Seed。
- 同一本书、同一执行代次和同一已应用阵容使用同一个持久化幂等键。处理范围冻结为该阵容的角色 ID，模型和温度读取创建任务时所属运行的不可变合同。
- `execute` 是低优先级工作：正文正在运行或 V2 开关关闭时返回 `deferred`。等待不消耗失败重试次数，实际生成失败最多尝试三次。
- 外显资料只填空白，提交前重读并按字段比较，保留作者修改及已保存资料。不写人物位置、背包、关系状态或章节事实，不重建动态投影。
- 角色思维只初始化缺失项；已存在的正文回填思维不得重置。生成前和事务提交前核对版本、代次、阵容及后台租约。
- 使用已注册 Prompt，复用书级固定前缀和限额，不拼接全书正文，也不新增逐章补全调用。调用归属当前小说和 V2 运行，不计入已闭合的正文作业用量。
- 公共服务在执行时实例化，避免世界网关、事件注册与补全适配器形成导入时初始化循环。

此补全不替代“最终修复正文保存 → 必要资源回填 → 下一章”的主链路。当前触发点是成功的正文批次结束；不会扫描旧库或补跑历史任务。
