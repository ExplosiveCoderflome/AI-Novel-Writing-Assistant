# 角色位置连续性

本模块拥有导演 V2 的正文位置投影、来源验证和章前读取。`Character.currentLocation` 仍属于基础档案，不作为跨章更新目标。

统一资产抽取提供时间语境、移动类型、一致性判断及原句。投影只校验结构化判断、身份、重复角色和正文证据，不通过关键词推断位置。保存时在当前正文事务边界写入专属检查点。资产恢复层记录消费完成并保证下章开启前完成，不另行调用模型。

读取按章序逆序分页，逐角色继承最后有效位置，必须匹配本书、角色及最新正文版本。疑点跟随下一章上下文，回忆/梦境/计划/转述不更新现实位置。定位失败保留原状态，语义争议不变成全局失败；结构损坏属于完整性问题，不能静默降级成空位置。

外部通过 `index.ts` 消费；动态位置不得写入稳定书级缓存。历史缺少投影不会触发批量 AI 重读，新最终正文回填逐章形成记录。

位置模块通过 `runtime/artifactSync/contracts` 读取公共正文版本契约。该入口不导入抽取或恢复编排，避免“抽取调用位置服务，位置服务又导入整个资产编排”的循环依赖。

带 `debt` 来源的正文只保存候选位置与待核对信息，不能自动更新确认位置；该保守规则与角色状态、资源提案的质量来源规则一致。说明长度由 Prompt 指导，不新增因普通字符串长度触发整章重新抽取的严格校验。
