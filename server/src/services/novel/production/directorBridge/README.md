# 正文生产与新导演的结果边界

## 决策

章节生产链负责生成、审校、修复、保存与资产闭合；新导演只观察保存结果。独立 `directorNext` payload 保存 Run 身份和已有结构化问题决定，避免把新 Run ID 写入旧工作流外键。

## 当前规则

- 没有 `directorNext` 时保持原流水线 payload 与调用行为。
- 有身份时必须校验格式，损坏合同不能静默降为旧作业。
- 同一 Run 与章节范围复用同一作业，包括已完成与人工暂停作业；其他运行的活跃作业不能接管。
- 自动恢复必须使用条件更新保护人工暂停，不能清除 `pendingManualRecovery`。
- 新导演全书执行终点以调用授权范围为准，禁止用可变小说默认章数扩展。
- 质量闭合观察回调传递已有决定，不再进行一次审校，不改写决定。
- 当前正文是否闭合仍使用 `production/completion` 与对应内容哈希的资产边界，不能单凭作业状态。
- 用户显式恢复需在命令事务中处理旧停止事实与业务作业；后台轮询不得承担该动作。

## 依赖方向

本目录属于章节生产的结果协议，依赖共享结构化问题合同。实际导演服务在 `app/director` 装配，生产执行器和质量闭合服务通过此协议保存结果，不依赖新导演的控制表或编排器。
