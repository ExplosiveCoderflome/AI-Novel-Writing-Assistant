# 章节自动处理预算

`ChapterAutomaticAttemptService` 负责单个 GenerationJob 内的章节自动处理额度。唯一键为 jobId + chapterId，正文 hash 不参与预算身份；改变正文不能恢复额度。kind 区分质量修复与运行异常重试，两者竞争同一个唯一记录。

记录在调用模型前创建，含义是不可退回的预算预约，不代表模型已成功响应。网络异常、取消发生在预约之后或进程中断都不退款，避免无法确认外部请求结果时重复计费。没有额度时局部修复保留正文并交给既有质量债治理；数据库读取/写入失败使用持久化安全错误停止调用。

恢复同一个 job 读取原记录；显式新建任务获得独立预算。历史没有记录的任务没有可靠的逐章消耗证据，首次执行此版本时按未预约兼容，不能将任务总 retryCount 猜测分配给某一章。

本模块不拥有导演命令租约，不保证整个章节只能由一个 Worker 执行。跨实例唯一性只保证自动处理额度只领取一次。导演 stale command 恢复仍需后续接入；不得宣称已完成 Worker 与章节共享预算。

部署前需执行仓库现有增量迁移流程。新增表迁移同时维护 PostgreSQL 与 SQLite；开发任务不自动迁移用户小说数据库。外部模块从 index.ts 使用本能力。
