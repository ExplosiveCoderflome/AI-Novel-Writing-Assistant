# 章节用量预算

只处理新导演正文作业的用量边界，不拥有生成、审校、修复、保存或导演恢复。使用 generationJob 的持久 totalTokens 和 directorNext 快照中的单章起始计数；同时记录 chapter_batch 规划计数的起始与结束边界，从作业总量中扣除本章边界之后发生的未来窗口规划。开始执行前保存检查点，恢复同章不得重置基线。正文运行时结束后、质量闭合中的后续规划前，必须保存 endJobTokens 与 totalTokens，失败不得启动后续规划。单章包含本章 JIT、生成、延长、验收、修复和资产同步，不包含未来章节的窗口决策和规划。作业总用量仍包含全部调用。计数或身份异常显式失败，不能猜测零用量。

结束计数存在时，旧快照必须满足 endJobTokens - startJobTokens = totalTokens；带规划边界的新快照则满足“作业增量 - chapter_batch 规划增量 = totalTokens”。已闭合预算不允许同一作业重新生成该章；恢复会按保存产物跳过已完成章节。历史快照没有结束计数时沿用原观测值，不根据总用量猜测、扣除历史规划消耗，也不自动解除已保存的安全暂停。

单章默认预算为 100,000 Tokens。新检查点采用 `uncached_tokens_v1`：输入减去已报告的缓存命中，再加输出及未分类的已报告用量；原始用量继续保留。旧检查点保留 `raw_tokens_v1`，不能在恢复时切换口径或清空计数。章节调用/重试之前和保存闭合边界检查。超限先保留完成进度，再返回结构化 runtime.token_budget_exceeded；新导演读取已保存决定并等待显式恢复。追加额度必须通过携带作业、章节和相同计量口径的恢复命令，只修改指定章的上限，不解除其他暂停、不重置历史消耗。不得调用旧导演熔断运行时或旧任务的用量台账。

保存边界的预算检查必须在本章质量报告、质量债和终态记录之后、后续章节规划之前执行。质量记录不发起额外模型调用；只有完成这些记录，恢复时才能按当前产物跳过本章。不能先抛出超限错误再记录质量结果，否则会留下“用量闭合、正文已同步、质量终态缺失”的不可恢复组合。

历史记录处于这种组合时，显式恢复通过 `qualityClosure/SavedChapterQualityRecovery` 核验当前正文的资产边界与精确版本的已保存验收结果，只补质量收尾，再处理后续章节。不重新生成、审校或修复本章，不重置基线、结束计数或自动处理额度。缺少同版结果、正文被修改、身份错位或计数倒退继续按完整性风险暂停；明确要求重规划或人工处理的结构化结果不能以补收尾方式放行，质量优先策略仍可暂停。

这项检查依赖模型返回并由统一用量跟踪保存的 Token 计数；不虚构未报告的用量。预算只保护尚未启动的章节调用和滚动规划，不回滚已保存正文。
