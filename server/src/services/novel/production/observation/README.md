# 正文生成的只读预览

## 背景与边界

导演阅读页通常读取保存版正文。为了允许用户观看生成过程，本模块提供临时预览，不能把模型输出片段混入数据库正文、导演产物台账或恢复检查点。

`ChapterPipelineRuntimeAdapter` 只在真正调用 Writer 时开始预览执行。`ChapterStreamGenerationOrchestrator` 发布初稿流片段；`ChapterWritingGraph` 在字数续写时通过同一执行发布合并后的正文。已有正文仅复查时不触发自动阅读跳转。审校、修文及资产同步的结构化输出不能作为正文片段展示。

## 契约

- 共享 `DirectorGenerationSnapshot` 拥有小说、章节、执行 ID、单调 revision 和完整正文快照。新执行替换该书旧预览；旧执行的迟到更新必须被忽略。
- `writing` 是未保存的正文流；`checking` 包含生成结束后的规范化草稿；`saved` 只在正文保存成功后发布，不表示资产同步或导演全流程完成；`interrupted` 不承诺正文尚未保存，正式结果须读取业务保存版。
- 无审校路径在其保存与收尾成功后发布 `saved`。保存失败必须发布 `interrupted`，不能把预览作为已完成章节。
- 缓存仅保留最多 32 本书、每书 100,000 字符、30 分钟未更新的预览。订阅错误、断线和慢读者不得改变生产状态或触发任何模型重试。
- HTTP SSE 只读，80 毫秒合并推送完整快照，重连立即回放当前快照，15 秒心跳；断线释放订阅与计时器。满写入缓冲的连接关闭后由客户端重连，避免积压。

## 前端与运行约束

“跟随生成”默认关闭，按小说存储浏览器偏好。开启时订阅本书，每个新章节执行聚焦一次并显示真实片段；关闭、换书或卸载时清理连接。正式内容重新读取成功后移除临时预览，避免遮住后续保存修改。

预览与自动/按阶段确认模式相互独立。任何预览操作都不确认阶段、不改变授权范围、不恢复人工暂停，也不增加模型调用次数。页面继续由 `DirectorBadge` / `DirectorPanel` 展示导演 `DashboardView`；阅读跟随只消费上述独立快照。

缓存适用于 API 与正文 Worker 同进程的开发运行方式。若部署独立 Worker 或多个 API 实例，应在本模块增加共享广播适配器，保留执行身份与快照契约，不能用伪造打字效果替代真实流。
