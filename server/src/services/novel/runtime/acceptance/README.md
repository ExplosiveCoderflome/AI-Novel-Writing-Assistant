# 验收输入与失败诊断

本模块拥有验收复用身份、专项风格上下文、安全失败诊断和 `retries/` 中的章节检查额度，不拥有正文写入或问题动作。耗尽后的继续/暂停由生产质量闭环应用任务快照。

身份使用 Prompt Registry 中的验收资产版本、经过上下文选择和槽位/高级模板覆盖的消息，以及解析后的模型配置。只持久化摘要，不保存 API Key 或完整提示词；外围运行包的生成时间不进入身份。

调用方通过 `index.ts` 使用能力。`ChapterAcceptanceAssessmentService` 提供身份查询，`ChapterQualityGateService` 负责内存复用、同实例在途合并及持久缓存。身份不可确认时跳过缓存而非复用历史结果。模型执行后再次检查身份，配置变化时不发布该次缓存。

身份准备复用现有提示词和模型解析 API，不发起模型请求。验收执行输入或 Prompt Runner 的覆盖规则变化时，必须同步检查这里的身份准备逻辑与隔离测试。同实例合并不承诺跨 Worker 的模型调用排他；检查次数通过 `retries/` 的持久预约和比较更新防止并发超额。

本书 `bookContract.narrativePov` 是执行依据，参考资产中的人称描述只是待转化技法。Writer、Acceptance 和 Repair 渲染同一优先级声明，不修改资产、不用关键词猜测参考写法；AI 从叙述正文识别人称并引用原句。人称与限知范围分别核对，角色对白中的“我”不能用于把第三人称限知判成第一人称。本书没有合法人称设置时不补造默认值；混合视角不强制转换为固定人称。

实际人称核对参与验收输入身份并随风格报告保存。AI 明确判断人称不符或无法确认时，必须保留叙事观察，不能由表达修文自动转换整章。只报告规则和实例拒绝的修改仍不领取额外风格修文权限。

失败按可信错误类型记录：风格报告、原句或规则引用校验失败；修文复验失败；结构化格式/传输失败；其他调用失败。风格校验使用自有类型和稳定原因代码，不解析供应商错误文本决定产品动作。安全原因进入风险标签及审校说明；日志带章节与 Prompt 版本，不保存供应商原始响应或密钥。调用完成但评估不可用时轨迹是 `degraded`，不能写成 `succeeded`；继续沿用不可用验收的质量债与缓存排除规则，不增加模型循环、不清除人工暂停。
