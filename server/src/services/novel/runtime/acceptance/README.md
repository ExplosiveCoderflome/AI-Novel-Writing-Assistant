# 验收缓存身份

本模块只定义验收复用身份，不拥有正文写入、问题动作或重试预算。

身份使用 Prompt Registry 中的验收资产版本、经过上下文选择和槽位/高级模板覆盖的消息，以及解析后的模型配置。只持久化摘要，不保存 API Key 或完整提示词；外围运行包的生成时间不进入身份。

调用方通过 `index.ts` 使用能力。`ChapterAcceptanceAssessmentService` 提供身份查询，`ChapterQualityGateService` 负责内存复用、同实例在途合并及持久缓存。身份不可确认时跳过缓存而非复用历史结果。模型执行后再次检查身份，配置变化时不发布该次缓存。

身份准备复用现有提示词和模型解析 API，不发起模型请求。验收执行输入或 Prompt Runner 的覆盖规则变化时，必须同步检查这里的身份准备逻辑与隔离测试。当前同实例合并不承诺跨 Worker 的排他执行；持久领取与恢复在后续预算阶段单独验证。
