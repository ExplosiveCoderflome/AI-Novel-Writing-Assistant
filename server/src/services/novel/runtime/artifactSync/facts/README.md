# 最终正文事实投影

## 职责与边界

本模块消费统一资产抽取结果，负责最终正文的摘要、关键事件、角色状态与事实写入，以及当前版本事实的只读投影。模型调用与消费者检查点由外层资产编排拥有，本模块不调用模型，也不调用导演状态机。

- `ChapterArtifactFactWriter` 验证保存正文版本后写入现有摘要与事实账本；V2 的关键事件和角色状态直接来自 AI 结构化输出。V1 保留旧摘要提炼行为。
- `loadCurrentChapterArtifactFacts` 对照当前正文 hash、成功抽取检查点和已写事实，供检索层生成来源明确的分块。返回 null 只表示 V1；无当前检查点不代表可以读取旧事实。
- 外部模块通过 `index.ts` 使用能力，版本 hash 使用父模块的纯内容版本契约。

## 索引与恢复

最终摘要/事实消费者负责安排 V2 正文和摘要索引。工作草稿与通用同步不重复安排，不按章重复重建整本书。异步索引不阻断资源回填；当前消费者写入失败则保留恢复边界，成功后由检查点防止重复消费。

事实账本仍是现有写作事实来源，不新建与它竞争的事实副本。读投影只把本次成功抽取且已经写入的事实送入 RAG；作者编辑后旧摘要不可以被重新标记为新正文版本。全书撤销与历史事实整理属于独立编辑契约。

详见 `docs/wiki/workflows/chapter-artifact-delta-reliability.md`。
