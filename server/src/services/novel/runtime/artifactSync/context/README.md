# 章节资产抽取上下文

本模块只把已读取的角色、资源和伏笔记录转换为模型输入，不读取数据库、不调用模型，也不决定导演的推进方式。调用方通过 `context/index.ts` 使用，资产同步总入口同时导出此能力。

`ChapterArtifactLedgerContext` 将身份目录与动态状态分开。角色按 ID、资源按 key、伏笔按 key 排序；资源和伏笔先保留既有最多 20 项近期选择，再稳定排序，排序不修改来源数组。目录不含更新时间、持有者、角色目标、兑现状态或历史证据。

动态行引用目录中的 key，保留最新所有权、持有者、可用状态、true/false 知识边界、限制、风险、使用与兑现窗口及短状态摘要。关键动态字段不使用字符串总长截断；历史 evidence/sourceRefs 由应用检查点保存，不重复发送到每章抽取输入。需要扩展条目选择时，应在上下文预算边界评估事实覆盖，不能用关键词筛选或冻结状态来提高缓存率。

目录每次从当前数据构建。身份修改或选中集合变化导致前缀变化是正常现象；测试证明布局和最新状态合同，真实命中与未命中 Tokens 以厂商报告为准。相关规则见 `docs/wiki/workflows/chapter-artifact-delta-reliability.md`。
