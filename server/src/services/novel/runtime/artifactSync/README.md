# 章节记忆恢复边界

本模块按正文版本保存一次记忆抽取结果，摘要、事实、资源、伏笔、位置等消费者只在完整抽取通过校验后逐项应用。恢复同一正文时复用成功步骤，正文版本变化或运行归属变化必须拒绝旧结果。

V2 有活动取消/归属与额度守卫时，只有明确的结构化输出错误（thinking_pollution、incomplete_json、malformed_json、schema_mismatch）可以触发一次额外的完整提取。先失败并释放旧步骤，再检查活动任务及预算、重核正文版本，通过正常检查点重新认领。诊断作为临时请求数据传给模型，不把失败输出当成事实，也不由程序编造必填字段。

第二次失败直接保留失败状态，不递归、不重写章节、不绕过手动恢复或质量优先暂停。网络、数据库、并发、归属、正文版本及消费者失败不属于模型格式重试；没有守卫的独立/旧版调用仍保持原行为。正常成功路径不增加模型调用。检查点记录 serializationRecovery 以便验收真实额外次数。

已暂停任务的显式恢复仍由既有导演命令完成；更新程序不会偷偷清除 pendingManualRecovery。重新整理成功不代表内容与资源推断已通过文学或事实验收。
