# 正文补写资源边界

## 职责

本模块只计算补写的剩余篇幅和输出资源额度，不判断剧情是否兑现。语义判断由注册的 Writer / Acceptance 提示词完成；章节存储、流式展示和调用编排由 `ChapterWritingGraph` 持有。

## 合同

- 用与正文计数一致的非空白字符数，减去共享长度合同的整章目标、软下限、软上限，得到本次追加的下限、目标、上限。
- 原稿达到软下限则不为凑足目标额外调用；缺少有效范围时不猜测篇幅。
- 输出 Tokens 是剩余字符上限的保守资源估计，最多沿用原有 6000 Tokens，不是分词器或完成质量保证。
- 模型返回后再核对实际追加字符数。超出追加上限时保留完整原稿、记录拒绝原因，不裁切正文、不自动发起另一轮补写、不把超长候选传入后续审校或资产抽取。
- 流式补写是临时预览；终态 checking 必须使用核验后的结果。拒绝时恢复原稿。
- 达标、可读性和剩余剧情义务仍由 AI 审校。局部长度风险遵守现有质量债/质量优先政策，不自行升级为全局重规划。

外部模块从本目录 `index.ts` 使用预算计算；不得由预算模块访问数据库、调用模型或改变任务状态。
