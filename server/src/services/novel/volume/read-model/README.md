# 分卷事实读取

`readVolumeWorkspace` 供只读投影读取保存的规划事实。它复用分卷持久层读取与规范化，按活动版本、活动卷行、最新版本、旧大纲的顺序构造文档。旧格式兼容结果仅存在于内存。

禁止在此入口调用 `ensureVolumeWorkspaceDocument` 或 `NovelVolumeService.getVolumes`：它们可能恢复版本、回填卷行、同步执行字段并保存。投影不能使规划状态发生变化；显式规划命令继续负责这些持久化动作。

没有战略规划或没有卷时，导演事实读取器返回 `null`；数据库或规范化异常继续向调用者传播，不能将读取失败判断为缺少规划。章节执行进度由独立的进度检查器读取，不通过分卷投影回写。
