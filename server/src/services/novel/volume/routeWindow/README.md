# 章节路线窗口的追加保存

滚动窗口只补缺，不是作者要求的整卷重生成。生成结果不能改变已保存的卷属性、章序、章节 ID、任务单、场景和节奏；候选与写入事务内最新规划合并，只追加缺失章节、后续卷或节奏。正文表仅补建缺少的空章节，既有正文与执行字段保持原值。

`NovelVolumeService.appendMissingRoutes` 是该保存边界的公开入口；合并策略属于此目录。读取原始规划而非通过 Chapter 空字段回灌。版本并发保护、规划、章节链接与空章节创建同事务完成，不能先持久化模型的全量候选再检查是否覆盖。

完整规划版本与关系表共同构成保存事实。事务内用关系表的真实列读取最新任务、场景等并发编辑；开卷钩子、压力与卖点、节奏归属、章节独占事件、出入状态和写法约定只在版本文档中持久化。关系表映射为这些字段填入的 `null` 是占位，不是作者清空指令，合并时必须保留版本值。不能用整份关系表投影覆盖完整版本，否则路线虽补齐，前文的生产约束已经丢失。

生产计划的 preservesInChapterRange 是有条件的写入合同，只适用于冻结的有效章节范围与上述追加适配器；整卷重生成仍遵守受保护内容守卫。受保护标记必须传递到后续路线产物，不能通过清除标记恢复。
