# 单章执行合同准备与提交

本目录拥有单章执行合同的来源读取、连续性/生成编排和事务提交。旧门面保留原有 singleflight、默认服务与事务实现；新调用方使用独立的准备、求值、提交端口，不进入跨运行共享的 singleflight。

准备端口必须显式提供只读工作区读取、模型编排与样式读取。`getVolumes({ hydrateCanonical: false })` 仍可能补建卷记录，不能作为只读来源。准备结果可序列化；每次真实 Prompt 的持久预约与结果回执由调用方负责。

提交使用调用方事务，归属检查在写入前后各执行一次。新端口同时检查 Chapter 原始内容/版本和卷工作区来源快照；调用方必须先锁定小说归属，并在同一事务保存提交回执。事件应在外层事务成功之后发布。默认兼容路径保留原有规划字段及前文检查。
