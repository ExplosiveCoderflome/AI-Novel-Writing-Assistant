# 已有执行合同与实际前文

结构齐全、与章节表字段一致，只能证明合同可以被读取，不能证明仍承接上一章实际结果。本模块复用现有任务单质量评估器，对尚无正文的章节在进入写作前核对前章正文。

正常入口经过 `ChapterExecutionContractService`：可复用合同若没有对应有效核对，则执行一次 AI 语义检查；需要调整时把结构化指导送回现有合同生成链，保留其生成次数边界。副驾模式的不可同步结果保留给作者确认，不能静默覆盖规划。已有正文的章节不重新生成合同。

`chapter_execution_continuity:v1` 只缓存相同实际输入的 AI 结果。身份包括前章完整正文、当前合同、模式、Prompt 版本、实际消息及明确的模型配置；没有明确模型身份时不复用。它不是仅凭前章尾段、更新时间或“字段齐全”颁发的通过标记。Prompt、模板、正文或任务变化都须重新核对。生成期间源正文或目标规划变化时拒绝过期写入。

该检查属于规划准备，不占正文审校/修文复验的额外请求额度，也不重置其记录。选定章节范围可核对当前合同，但不能因此扩展路线窗口或授权正文范围。

Writer、Review 和 Repair 都读取最近一章完整正文作为物理事实来源；只保留这一章，避免把全部历史变成必需输入。摘要、状态资料和未执行规划不可反写来源事实；有依据的字迹显现、移动和持有变化仍由 AI 判断，不能冻结为永不改变的状态。
