# 世界关键设定的回答整合

回答整合以结构化手册为主源，由注册的 AI 资产返回稀疏变更与逐题总结。集合按 AI 给出的实体 ID 合并，只新增或更新；未提及的字段和实体、地图信息、已有关系必须保留。旧字段标签不承担语义分类。

模型调用位于事务外；手册版本、更新时间和结构，以及提交问题的更新时间在写入时重新核验。手册、派生文本、回答状态与快照同事务保存；失败不得把问题标成整合完成。问题的 integratedSummary 保存版本化 JSON 回执（summary、answerHash），使重放不重复调用模型。旧纯文本回执的回答可以显式重新整合到结构化手册。

此模块只维护外部世界样本，不自动推送小说内的世界副本。客户端在来源页展示回答与整合摘要，失败保留草稿；并发输入只能清理本次已成功提交且内容未变的草稿。
