# 单章规划端口

本目录拥有单章规划的只读来源读取、完整注册请求构造和结果投影。`PlannerService` 保留默认门面；书级、分段规划和重规划决策不由此目录接管。

- `prepareChapterPlan` 只读取输入并构造原生请求，不调用模型或写业务数据。调用方可冻结其请求、源版本及投影所需的数据。
- `executePreparedChapterPlan` 只执行已准备请求并规范化模型结果；从序列化记录恢复时核对注册资产版本，并使用当前正式资产实现。
- `projectChapterPlan` 只将同一份准备数据和规范化输出映射为持久输入；调用方选择带事务围栏的提交端口。
- `readInputs` 接收显式来源依赖；新内核使用 strictSources，读取失败不能伪装成空账本。旧门面保留既有可选来源降级行为。

完整模型输入与提交授权是两个边界。准备成功不能授权失权后的提交；结果保存和业务提交之间的恢复，由调用方的子请求/提交回执负责。规划模块不导入生产内核或导演模块。
