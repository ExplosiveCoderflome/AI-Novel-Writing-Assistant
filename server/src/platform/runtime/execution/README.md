# 执行取消边界

此模块只携带当前异步执行的 AbortSignal，不拥有导演状态或恢复决策。Worker 将一次租约执行放入该作用域；续约失败、失去租约、租约到期或停止服务都会撤销该执行。

正常执行收束也撤销该作用域，防止遗留异步任务在租约释放后继续写入。惰性的 PrismaPromise 必须在作用域内部 await，不能将未消费的 thenable 直接返回到外层上下文再执行。

LLM 适配器合并调用方与作用域信号，取消在途请求；Prisma 入口在后续业务查询/写入前拒绝已撤销的执行，事务内后续操作抛错会回滚该事务。取消前已提交的结果保留，已经发出的数据库操作不能由 AbortSignal 撤回。调用计费记录属于观察事实，允许在取消后登记真实用量。

不处于作用域的手动保存、修订同步、HTTP 查询与 Worker 租约维护保持原行为。外部只经 index.ts 使用，不把信号持久化为质量判断，不允许据此自动解除人工暂停。
