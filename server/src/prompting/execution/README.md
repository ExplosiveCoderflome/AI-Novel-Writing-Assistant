# 有效 Prompt 的只读准备

`prepareEffectivePromptExecution` 与正式 PromptRunner 共用覆盖、上下文选择、官方渲染、高级模板和结构化输出提示。它返回完整有效消息，不调用模型，不写业务记录；覆盖与模板读取保留各自既有的数据来源。

调用方可以据此计算完整输入指纹和预算。这个入口不冻结调用方的执行权限，也不代替真实请求前后的配置、租约、版本及用量检查。读取后发布了新模板或改变模型配置时，应拒绝旧身份结果，不能把预检当作长期授权。

新增产品 Prompt 仍通过 `prompting/prompts/` 的注册资产提供，本目录不拥有审校语义、补丁策略、模型重试或业务持久化。
