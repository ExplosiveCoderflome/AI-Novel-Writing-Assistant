# 结构化响应读取边界

`JsonValue` 是无外部依赖的完整 JSON 提取入口。先解析原始值，仅移除最外层代码围栏；候选必须完整、语法合法且唯一。不得通过补括号、删除字符串内容、裁剪数组或补造业务字段让损坏输出通过校验。

`ResponseCollector` 在内存中将最终文本、推理和结束信息分开。思考标签可跨 chunk，但 JSON 正文开始后的同名字符串属于数据。原生推理块不进入正文。原始 SDK 响应仅用于取供应商扩展字段，不默认写入文件。

显式 `length/max_tokens` 即使伴随合法 JSON，也表示输出未完成。结构化入口必须停止同额度的格式降级/修复；调用方可以缩小任务范围后重新生成。`StreamCapture` 复用同一读取策略，并传播取消和传输错误，不能把断流当完成。

诊断日志仅保留结束原因、字符数、token 用量和结构错误。修复模型的生成结束使用 `repair_generation_done`；通过校验才记录 `repair_done`。全文调试内容必须显式启用 `LLM_DEBUG_INCLUDE_CONTENT=true`，日常排障不需要该开关。
