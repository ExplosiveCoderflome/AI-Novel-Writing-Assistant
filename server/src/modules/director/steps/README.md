# 导演生产步骤适配边界

## 职责

步骤处理器只适配底层小说业务服务，返回可落账的产物引用。内容本体由业务服务保存，台账由 `RunExecutor` 写入；不能让步骤直接更新导演控制状态或再次启动旧导演流水线。

`StepResult` 支持 `debts[]` 和显式 `stopSignal`，保留旧的 `debt` 字段兼容。执行器先写质量与停止事实，再写产物；停止信号经领域守卫校验并持久化，由编排器处理，不能由步骤直接暂停控制表。产物保存后崩溃时，已保存的停止事实仍须阻止下游推进。

`planDefinition.ts` 定义生产步骤依赖，不意味着这些处理器已可执行。生产计划只有在启动输入、模型快照、全部处理器和范围处理接通后才能替换默认装配。

## 依赖方向

步骤通过注入的服务端口调用生成能力；数据库、内容哈希和种子读取由基础设施与装配入口负责。不得直接依赖旧 `services/novel/director` 下的阶段、运行时或编排器。

故事宏观处理器接收故事服务、运行输入读取器和内容哈希函数，尚未注册到默认 Worker。输入读取器接收完整 `StepContext`，必须解析当前 Run 保存的故事想法和模型选项，不能读取可变的书级默认值冒充运行快照。其桩测试只证明适配调用和返回值，不证明真实 AI 调用或整本小说生产成功。

## 生产约束

`execution_contract_sync` 将窗口内已准备的任务单和场景计划同步到真实章节，固定 `preserveContent=true`、`applyDeletes=false`。现有业务服务的 `executionContractChapterRange` 只限制合同检查，全书路线元数据仍同步；不能将它描述为只写窗口内章节。前后读取全部章节，任何既有章节丢失、正文改变、窗口内合同或执行参数不一致都返回数据完整性停止信号。产物引用包含运行作用域与执行窗口，哈希只覆盖保存后的窗口执行合同，不包含正文。

`chapter_detail_bundle` 只细化输入快照指定且位于授权章节范围内的目标，以 `task_sheet` 模式复用底层一次生成完整执行合同的能力。质量回调保留原 AI 评估与门禁结果，不修改 Prompt、质量算法或旧默认行为。全书生成模式负责保留结构可用的内容；是否继续、局部修补、重规划或人工暂停，由注入的结构化问题决策端口处理，不能由文案推断。完成优先下局部质量债继续；只有质量优先且明确决定 `pause_for_manual` 时返回人工暂停信号。

业务保存成功且目标任务单、场景计划仍存在后才能落账，保存不隐式同步章节执行。缓存复用沿用底层服务原规则，不伪造新的语义评估。问题决策服务的真实装配、启动快照和 Worker 注册仍未完成；不能将桩决策作为线上 AI 实现。

`book_contract` 通过注入端口调用独立书级创作约定生成服务及现有保存服务。小说 ID、调用任务 ID 和入口来自当前 Run，不能沿用输入中遗留的旧运行身份。保存错误直接传播；保存记录没有 ID 或不属于当前小说时，禁止返回产物引用。只有保存结果用于内容哈希，不对尚未保存的草稿落账。

`world_setup` 先检查已有世界。没有世界时调用底层网关生成，再取得已保存的角色用途世界切片并计算哈希。已有世界不重新生成，因网关没有提供作者来源，保守地将其标为受保护的确认产物。上下文为空必须失败，不能落空台账。世界跳过模式尚无持久化产物合同，不在此处理器中伪造“已准备世界”。

`volume_strategy` 依次调用底层分卷服务的 `strategy`、`strategy_critique` 和 `skeleton`，将上一阶段草稿传入下一阶段。关闭中间结果保存，最终保存成功后才计算产物哈希；保存时明确设置 `syncToChapterExecution: false`，不能因为后续章节缺少执行合同而阻止分卷策略保存。模型输入和目标章数由本次运行输入提供，阶段失败直接传播，不把部分草稿记为完成。

`volume_beat_sheet` 读取当前 Run 选定的目标卷及工作区，只调用一次 `beat_sheet` 生成。生成前检查小说归属与目标卷存在，保存前后均检查目标卷节奏板有节奏段；空结果、其他卷结果或跨书结果不得落账。保存关闭章节执行同步、伏笔同步和事件广播，产物引用包含目标卷 ID，哈希仅计算保存的目标节奏板。本步骤不循环生成全部卷，也不校验尚未生成的章节执行合同；输入读取器须从结构化授权输入提供目标卷，不以文本猜测或默认第一卷替代。

正文批次只观察章节生产链闭合结果，不重复执行审校、修复、状态提交、伏笔或角色同步。局部质量债必须记录并允许后续章节继续；全局停止只能来自结构化停止信号。
