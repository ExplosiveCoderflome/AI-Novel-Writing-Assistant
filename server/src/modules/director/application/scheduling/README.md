# 排队状态与显式重启

本模块只将 Run 的创建时间、租约与本进程 Worker 状态投影为等待、其他作品处理中、启动中、重试中或暂不可用。不改 Run 状态，不启动 Worker，不把排队映射为质量失败。

有效租约优先于进程内状态。其他作品仍在正常执行时解释串行等待；后台未启动、正在恢复或无有效租约且排队超过一分钟时，来源导演台可展示 retry_start。客户端只使用服务端投影，不按前端计时或错误文案猜测权限。

retry_start 是显式运行命令：保持原 Run、范围、正文和用量，在版本、归属及无有效租约的事务条件下重新登记 queued 边界并唤醒 Worker。它不等同 resume，不允许处理 paused、waiting_gate、running 或终态，不调用章节业务恢复。重复命令只重放结果并再次请求幂等唤醒，不创建新 Run。

运行记录仅展示状态与来源链接，不渲染重启动作。进程内健康信息适用于当前单进程装配；分离 Worker 部署须共享健康事实后才能判断 unavailable，不能仅凭 API 进程没有 Worker 抢占远端有效租约。
