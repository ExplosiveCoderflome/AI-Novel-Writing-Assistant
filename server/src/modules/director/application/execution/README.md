# 导演执行租约

Worker 拥有排队、常驻轮询与执行监督；RunLeaseSession 拥有单次领取后的续约、到期计时和撤销信号。执行器与业务步骤仍拥有原阶段规则，不在租约模块做质量判断。

一次执行只允许一个续约请求在途；请求失败或返回 false 均撤销当前执行，不能只打印日志后继续。租约到期计时独立于续约请求，数据库请求卡住时仍能取消模型调用。Worker 等待当前执行收束后才领取其他工作，不用 Promise.race 遗弃旧执行。

每次领取都有独立 owner，不能只用进程标识；迟到的心跳与释放操作不能修改同进程下一次领取的租约。正常阶段边界按 owner 条件释放，不要求下一阶段等待到期。生产组合入口注入基础设施 executionScope 适配器，应用内核只依赖取消端口，不直接导入 AsyncLocalStorage 或数据库。

正常步骤错误沿用原任务的有限重试和人工恢复；租约故障属于调度设施故障，不消耗章节的模型修复次数，也不能暂停或修改另一个执行者拥有的任务。取消前已保存的阶段产物保留，重启后按既有台账恢复。
