# 手机快捷终端边界

手机使用既有 `useIsMobileViewport` 的 767px 断点，在 AppLayout 渲染终端门面；桌面保持原路由和工作台。`routePolicy` 只负责显示入口，不承担 AI 意图识别或服务端权限控制。复杂工具的直接链接也不能挂载桌面编辑器，避免设置弹窗、大表单和导出工具从深链重新出现。

小说列表、书内章节、正文小改、本书任务、运行记录和通知是终端能力。运行记录只读并保留来源路由；任务继续、重试、暂停、取消位于展示本书内容和保存进度的小说页。模型额度、未知调用结果、重规划或安全问题需要电脑端核对，不以普通继续按钮绕过原恢复合同。

正文小改复用章节编辑器的草稿门面和原保存接口，发送保存基线正文与时间。轮询不覆盖未保存修改；并发正文变化保留本机草稿并禁止覆盖，载入新正文需用户明确确认。不要在手机模块重新实现章节草稿存储、自动修复或任务状态写入。

V2 继续、重试、取消复用既有命令及版本围栏；主动暂停复用手动恢复状态和幂等命令。V1 复用任务继续／重试／取消，暂停设置原任务与绑定管线的手动恢复锁。通知只导航到来源小说，不在通知或记录列表执行批量任务操作。

通知书级链接复用 `novelRoutes`，运行记录状态复用运行记录展示工具，V1 暂停入口读取 `dashboardView`。不要在手机模块拼接任务编号 URL，或根据恢复锁、检查点和原始等待状态重新推导展示状态。
