# V2 生成跟随与资料刷新

## 职责

本模块通过 `index.ts` 提供正文 SSE 预览、跟随偏好、阶段导航和保存资料刷新。它只影响本书阅读选择与查询缓存，不提交导演命令，不写业务资料，不接管 V1。

## 两条独立链路

- `useWorkspaceActivity` 始终消费 V2 投影的资料版本。版本包含 Run、控制边界和台账产物版本；每次状态轮询不等于新保存。`workspaceRefresh` 合并并串行读取，较旧请求完成后补读期间收到的最新版本。读取失败等待下次状态轮询重试，卸载后禁止补读。
- 本书目录正文缓存与伏笔／资源缓存使用独立刷新协调器，观察同一保存版本。伏笔或资源查询失败不能让成功刷新的正文持续重读；未打开的台账只标记失效，打开时再读取。每个协调器仍独立遵守串行、补读和切换书籍销毁规则。
- `useGenerationFollow` 仅在用户开启跟随后订阅正文快照。`model` 优先以流中的真实章节 ID 定位正文；其他阶段以投影的产物类型定位故事、世界、角色阵容、分卷和章节规划。目标卷或章节必须唯一匹配，缺失时展示所属资料总览，不能用第一条资产冒充目标。

## 焦点边界

工作台按阶段键／正文执行 ID 与选择身份定位一次，禁止把正文 revision、Token 内容或整个查询响应当作焦点 effect 的依赖。资料刷新后目标首次出现可以重新定位；同一阶段的手动浏览保留到下一阶段。关闭跟随停止自动导航，资料刷新仍继续。

资料页可展示生成提示和已保存事实；正文快照是临时阅读层，不能写入 `WorkspaceBook`、任务种子或恢复检查点。等待确认时打开资料不代表确认；所有变更命令仍由导演台负责。
