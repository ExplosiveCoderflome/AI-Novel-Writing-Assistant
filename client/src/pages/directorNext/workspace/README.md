# 小说资源工作台

## 责任边界

通过 `index.ts` 向小说导演页提供资源目录、正文阅读和角色查看。只读取保存的业务资产，不推断自动导演状态、不生成或修改小说。`WorkspaceBook` 排除旧书架接口中的运行进度；导演控制仍由 `DirectorPanel` / `DirectorBadge` 消费后端展示投影。

## 数据与交互

- 保存资产来自现有 `simple-shelf` 只读接口，包括故事约定、世界摘要、角色摘要、卷纲摘要及章节正文；不是完整故事宏观规划或全部资产字段的编辑器。
- 完整卷、节奏段、章节规划来自 `volumes` 只读接口；`planning.ts` 以保存的 `beatKey` 分组，以 `chapterId` 优先、缺失时同书 `chapterOrder` 关联正文。禁止以节奏段范围提示猜测归属，失效正文 ID 不以序号替换。未关联内容保留独立入口，无正文规划仍可查看目标。
- `PlanningDetail` 提供卷与节奏段详情及正文归属导航；目录只默认展开选中内容的所属分组，本书目录与导演台均可收起。应用壳在工作台路由隐藏常驻全局侧栏，菜单采用临时浮层。
- 资源目录轮询刷新，选择保留有效的资产 ID；切换书籍时重建工作台。阅读器保留打开时的正文版本，同一章节的新保存内容须由读者点击加载。
- 角色抽屉读取角色时间线。默认仅显示阅读章节及以前且标注章节顺序的记录，未知章节记录不属于历史阅读范围。点击章节来源返回同一工作台。
- 现有角色动态总览中的 `currentState/currentGoal` 是可变的最新字段，传入 `chapterOrder` 不能得到历史快照。只有读者选择“最新状态”才读取和展示；禁止将其标为“本章状态”。
- 角色快捷入口是本书角色列表，不代表本章全部出场角色；不得通过正文关键词猜测出场关系。
- 预览禁用网络查询和创作命令，示例历史由 `previewBook.ts` 提供。

## 布局边界

目录与正文、正文与导演台通过 `components/layout/resizableWorkspace` 共享宽度调整能力，复用项目已有的 `react-resizable-panels`。分隔线提供鼠标和键盘调整、双击默认比例复位，宽度偏好仅存本地浏览器；存储不可用时仍可调整。容器通过 ResizeObserver 测量可用宽度，无法满足最小阅读宽度时上下排列。禁止将布局偏好写入小说业务资产或导演运行快照。产品原则以 `docs/design/product-ui-design-system.md` 为准。

## 维护

业务资产和导演投影错误各自展示，不允许导演查询错误隐藏正文。此模块只负责阅读，不改变旧小说工作区、运行记录或生产流程。关系、资源、情绪等历史字段需有可信的逐章数据契约后再加入。
