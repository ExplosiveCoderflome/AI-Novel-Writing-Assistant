# 导演正文与章节计划编辑入口

本模块只负责从导演 V2 阅读或审核页打开共享章节编辑器。正文草稿、AI 候选、快照与并发保存由 `ChapterEditorShell` 及其已有模块管理，不能在此复制执行链。

父页面暂停跟随生成，并通过保存完成回调刷新本书工作区和当前阅读版本。关闭弹窗要检查共享编辑器上报的进行中操作、未保存正文和待采纳候选；返回保持原章节或审核上下文。

正文编辑弹层占满视口，覆盖共享对话框的外边距、最大宽度和圆角。光标和选区的 AI 操作由共享编辑器放在正文外的右侧区域，入口层不能重新添加遮挡正文的浮动菜单。

`DirectorChapterPlanEditor` 负责章节任务与场景的表单。入口由导演台当前确认门授权，小说页只提供内容渲染函数，不能自行消费导演状态来决定编辑权限。提交携带打开编辑器时的字段指纹和门控版本，通过 `confirm_after_edit` 同事务保存并确认；不调用整份卷工作区覆盖接口，不修改正文。场景在归一化前逐个校验，错误保留表单，未保存修改关闭前提示放弃。书级缓存刷新后仍保留打开表单时的版本指纹，防止旧输入覆盖其他来源的新修改。
