# 导演正文与章节计划编辑入口

本模块只负责从导演 V2 阅读或审核页打开共享章节编辑器。正文草稿、AI 候选、快照与并发保存由 `ChapterEditorShell` 及其已有模块管理，不能在此复制执行链。

父页面暂停跟随生成，并通过保存完成回调刷新本书工作区和当前阅读版本。关闭弹窗要检查共享编辑器上报的进行中操作、未保存正文和待采纳候选；返回保持原章节或审核上下文。

正文编辑弹层占满视口，覆盖共享对话框的外边距、最大宽度和圆角。光标和选区的 AI 操作由共享编辑器放在正文外的右侧区域，入口层不能重新添加遮挡正文的浮动菜单。

`DirectorChapterPlanEditor` 从导演台确认门接收本批规划行，按规划行 ID 保留各章编辑稿和待发消息。发送讨论以及批量确认沿用打开时的规划版本。建议只能采纳到发起对话的章与场景字段，需与提案原值相符。全批确认只提交有修改的章，异常时保留输入。具有正文授权时，确认按钮携带打开时的整批指纹，服务端核对保存和同步的执行要求后才进入正文。

角色阵容与卷纲确认共用 `DirectorReviewAssetEditor`。表单保留打开时看到的字段，只提交实际修改的项。保存和继续使用同一条幂等命令，字段冲突时保留输入，作者可返回查看最新资料。角色中途调整仍从角色详情页进入。

`discussion/ReviewDiscussion` 在当前角色、分卷或章节的会话中显示建议，按该字段对应的编辑稿原文检查能否采纳。编辑器按资料 ID 和字段保留本次修改。卷纲编辑器冻结活动卷纲版本，发送讨论和确认命令时沿用这一版本，防止工作台刷新将旧输入套用到另一份规划。
