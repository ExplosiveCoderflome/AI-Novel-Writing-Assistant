# 正文反馈审阅边界

本模块由大纲工作台装配，外部仅通过 index.ts 使用面板和入口可见性策略。小说来源条只提供导航，不挂载分析面板。仅桌面且绑定反馈资格明确为 true 时装配，不能用 CSS 隐藏代替装配判断。

- OutlineFeedbackPanel 负责读取、来源章选择、频率设置装配与运行列表；后台轮询只读，打开面板不自动启动模型。
- FeedbackSettings 保存完整设置并保留 provider/model；失败保留本地选择。
- FeedbackRun 负责显式选择、采纳、拒绝、重试和过期重新分析。每次仅提交待确认项 ID，不能转到通用 A1 采纳入口。
- feedbackModel 只做设置校验、结构化权限和状态后处理，不承担创作意图判断。
- 对比左侧取服务端分析快照，不从正在编辑的大纲猜测原值；采纳链接读取确切 revisionId。采纳后失效本项目和绑定小说缓存。

后端仍是版本、摘要、策略、规划与未来章节保护的权威。客户端提前禁用不替代事务校验；409 必须保留建议并要求重新分析，不能暗中重试采纳。
