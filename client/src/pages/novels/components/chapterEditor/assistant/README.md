# 章节 AI 操作面板

本模块呈现待生成候选时的唯一 AI 操作区域。`ChapterEditorShell` 提供当前目标、受控补充要求和既有执行回调，`ChapterEditorActions` 不维护正文、光标、候选或请求真源。

当前主动选择的问题卡优先于其定位选区；手动选择正文或点击光标后，切换到对应的局部操作。没有手动目标时可显示 AI 推荐的首要问题，整章操作由明确选择开启。切换目标保留同一份补充要求，预设续写和改写都使用它；诊断分析不会禁用输入。

问题卡的目标、改法和保留项来自 AI 结构化诊断。面板负责展示和提交，不根据标题关键词生成修复目标。诊断直接处理继续走 Shell 的版本检查、定位和请求链路；候选生成后的差异比较、采纳与保存仍由原有 review 和 draft 模块处理。
