# 章节待处理问题

`ChapterEditorDiagnosticList` 展示 AI 推荐的首要问题并折叠其余问题，推荐无法关联时保留诊断返回的顺序，不使用严重度标签重新决定阅读优先级。展示模块只回传定位、直接处理和来源问题确认动作。

`workspaceState` 负责成功保存后的当前诊断投影：移除完整采纳的问题及其推荐任务，并按确定的正文替换同步其他卡片坐标。交叉覆盖且无法确定新位置时清理旧定位，要求重新分析；不能靠标题或文本相似度猜测问题已解决。

真实审校问题关闭、正文版本校验和候选来源由 Shell 管理。无持久化来源的问题只更新当前诊断缓存；拒绝、部分采纳和失败不移除卡片。任何缓存更新都不自动再次调用诊断 AI。
