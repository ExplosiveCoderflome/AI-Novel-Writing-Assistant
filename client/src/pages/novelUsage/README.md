# 小说 AI 用量与调用日志

本页面是本书的只读用量查询，路由为 `/novels/:id/ai-usage`。导演台标题栏和书架提供入口；不启动、恢复或改变任何创作任务。

页面与小说导演台共用隐藏左侧全局导航的桌面布局。全局导航由顶部菜单按需打开，不因查看日志改变用户保存的侧栏折叠状态。书架仅对指向新导演台的小说显示入口，与服务端导演查询的启用边界保持一致。

- 顶部 `summary` 统计本小说全部已记录物理调用，筛选与分页不改变全书合计。
- `filteredSummary` 覆盖当前筛选的全部记录，不只当前页。明细使用服务端游标分页；筛选进入 URL 和查询身份，切换筛选重新读取第一页。
- 缓存命中和未命中放在输入 Tokens 内；不能再次加到总用量。书级缓存仅展示已报告部分，并显示覆盖调用数；逐次无效报告显示统计不可用。
- null 是未提供；显式 0 是真实零。未知和部分返回必须提示覆盖缺口。页面不声称还原未记录的历史花费，也不按字符估算。
- 自动刷新只读取最新一页。展开历史分页后停止自动轮询，刷新按钮重置到最新页，避免反复抓取所有已展开历史。
- 普通内容使用文字、间距和分隔线，表单控件才使用边框。交互验收由使用者进行，默认不添加浏览器测试。

`components/UsageOverview` 负责书级汇总与章节分组；`UsageLogTable` 负责逐次调用；`presentation` 只做已有结构化统计的展示和筛选参数校验。完整统计边界见 `docs/wiki/workflows/novel-ai-usage.md`。

`UsageTiming` 展示完整筛选范围的平均、最慢调用及章节步骤累计耗时；步骤累计包含重试和并行请求，不能当作章节墙钟耗时。TTFT 未报告时显示“未提供”，输出速率采用输出 Tokens / 调用总秒数。

`InvocationDetail` 只在展开行或定位调用后查询消息、原始回答、解析结果/错误和尝试链。长内容默认收起，支持复制。`invocation` URL 参数可定位历史分页之外的调用：独立读取本书调用并插入当前列表，不改变筛选统计；界面须提示该行可能位于筛选范围外。该参数不是授权凭据。

历史记录默认关闭，在“模型与厂商”设置天数与压缩后容量。载荷过期不删除调用计数与计时，详情应解释缺失原因，不能把未保存内容解释为空回答。
