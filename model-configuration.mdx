写作开始前，必须先在系统设置里配好至少一个可用的文本模型。工作台不内置模型额度，使用你自己的 API 配置。

## 基本配置

进入 **系统设置 → 模型供应商**，填写：

1. **供应商**：选内置供应商，或新建一个 OpenAI 兼容的自定义供应商
2. **API 地址（Base URL）**：供应商的接口地址；官方直连用官方地址，中转服务用中转商给的地址
3. **API Key**：你在该供应商处的密钥
4. **文本模型**：填写模型名，保存后点 **连接测试**，通过后再开始创作

## 三种常见接法

| 接法 | API 地址填什么 | 说明 |
| --- | --- | --- |
| 官方 API | 供应商官方地址 | 如 DeepSeek、OpenAI 等官方平台，稳定、计费清晰 |
| 中转 / 兼容服务 | 中转商提供的地址 | 只要兼容 OpenAI 接口格式即可接入；模型名按中转商给的名称填 |
| 本地模型 | 本机地址 | Ollama 默认 `http://localhost:11434`，LM Studio 默认 `http://localhost:1234`；先启动本地服务再做连接测试 |

## 模型路由：不同任务用不同模型

规划、正文、审阅、拆书对模型的要求不同，可以在模型路由里分别指定：

- **规划类步骤**（世界生成、大纲、拆章列表）：建议用能力强、输出稳定的模型，速度太慢的本地大模型容易在长输出时超时
- **正文生成**：建议用文笔和上下文长度合适的模型
- **审阅 / 修文**：可用性价比更高的模型

## 常见问题

**生成到一半被截断 / 输出长度不够**
在模型路由里为该模型显式设置足够的输出上限（maxTokens）。你的显式设置优先于系统默认值，设置太小会让长章节或结构化结果被截断。

**结构化步骤报错或返回空内容**
规划步骤需要模型返回严格的结构化结果。思考型（推理）模型在这一步可能把输出额度耗在思考过程上、正文为空；可以为规划步骤换用非思考模型，或在供应商支持时关闭该模型的思考模式，正文步骤不受影响。新版已内置模型兼容层，会自动探测并降级不兼容的结构化输出方式，遇到这类问题先升级到最新版本再试。

**本地模型总是超时**
本地大参数模型生成速度有限，规划这种长输出步骤更容易超时。先把规划步骤路由到云端模型、本地模型只跑正文，或换更小的本地模型，并确认本地服务全程开着。

**连接测试通过、生成还是失败**
连接测试只验证地址、密钥和模型可达；生成失败请看导演台给出的暂停原因和运行记录，多数情况是额度不足、模型路由未配置到对应步骤，或输出上限太小。反馈问题时带上版本号、所用模型和报错原文，定位最快。
