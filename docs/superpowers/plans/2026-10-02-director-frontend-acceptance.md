# 小说导演台前端验收

## 范围

此次可验收的是方案 A 的前端展示：小说上下文、侧边导演台、七种状态、主动作、质量提醒、时间线、折叠诊断和窄屏排版。它不证明真实小说生成链路完成。

独立预览使用示例数据，禁用全部创作命令，不启动服务器、Worker 或数据库。生产适配计划 05 尚未完成，默认步骤注册表仍为空。不要通过打开 `DIRECTOR_NEXT_ENABLED` 来尝试端到端写书。

## 启动

在 `D:\code\ai-director-rebuild\client` 执行：

```powershell
pnpm exec vite --host 127.0.0.1 --port 5174 --strictPort
```

打开 `http://127.0.0.1:5174/director-preview.html#/lab/director/preview`。

## 操作

1. 逐项切换“正在推进 / 等待确认 / 保存进度暂停 / 重新规划暂停 / 风险暂停 / 创作中断 / 范围完成”。
2. 检查每种状态的一句话和主按钮是否清晰，范围完成是否无继续按钮；预览中的创作命令必须禁用。
3. 检查导演台的四个段落：正在做什么、需要你做什么、质量债、时间线。
4. 展开运行诊断，确认它默认折叠；质量提醒不应把正在推进变成失败。
5. 缩窄窗口，检查内容改为完整宽度，按钮可读、无横向溢出。

## 真实数据入口

正常应用的 `/lab/director` 读取跨书运行记录，`/lab/director/:novelId` 读取当前或最近一条新导演记录。旧导演记录不会自动转换。真实数据库和后端启用仍属于后续接通阶段，不在此预览的验收范围。
