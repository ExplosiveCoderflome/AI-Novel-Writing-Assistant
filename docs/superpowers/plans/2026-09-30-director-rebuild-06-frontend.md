## 已确认的视觉方向

用户在状态展示基础上选择“目录工作台”，批准实施资源目录、正文阅读、角色快捷抽屉和变化记录。此切片复用保存资产的只读接口，独立于新导演生产接通；不修改旧页面或导航。资源摘要不等于完整宏观规划/资产编辑器。历史角色范围禁止消费可变最新状态。实现边界见 `client/src/pages/directorNext/workspace/README.md`，验收步骤见前端验收说明。

导演面板以小说上下文为主：`/lab/director/:novelId` 在小说来源页旁展示右侧导演台，桌面端使用窄侧栏，移动端改为全屏段落；`/lab/director` 仅承载跨书运行记录和需要处理筛选。导演台固定回答“正在做什么 / 需要你做什么 / 质量债 / 时间线”，诊断信息折叠在末尾。

## Global Constraints

- 继承计划 00 第 3、6 节的全部约束。
- 遵守 `AGENTS.md` 的 UI 视觉规则：低边框层级；内容分组靠字体、间距、对齐、细微底色和分隔线；默认内容面不加边框和阴影；不嵌套边框卡片；阴影只用于浮层；不新增或安装 shadcn/ui 组件，使用项目已有的 `client/src/components/ui/` 原语。
- 遵守 `AGENTS.md` 的 UI 文案规则：从用户角度说明功能与下一步，禁止"现在 / 不再 / 已经 / 之前 / 原本 / 迁回 / 升级为"这类改动叙述。
- **只有 `DirectorBadge` 与 `DirectorPanel` 两个组件可以读取 `DashboardView`。** 其他文件读取它的展示逻辑一律违规，由守卫测试强制。
- 前端**不得**根据原始 Run 字段（`status`、`pause`、`gate`、`cursorStepId` 等）自行推断主状态、主进度或主按钮；只渲染 `DashboardView` 的 `mode`、`headline`、`progress`、`availableActions`。
- 运行记录保持**只读**：只能查看、筛选、跳转到来源页，**不得出现任何改变运行状态的按钮**。
- 按钮来自 `availableActions`：`kind = "command"` 时提交命令，`kind = "navigate"` 时只跳转；页面地址里**不得出现任务编号参数**。
- P1～P5 期间不修改任何现有页面和入口，新组件只在 `/lab/director` 下使用。
- 界面验收由用户完成；执行者只做代码级检查（类型检查、客户端测试），不做浏览器或截图验证。
