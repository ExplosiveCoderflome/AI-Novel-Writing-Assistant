# 自动导演重构 · 计划 08：`open_run` 统一入口、legacy 适配器与入口切换（任务级，待细化）

状态：**待开发，任务级计划**。**不交给低阶 LLM**：涉及真实入口切换和旧数据展示，由我亲自或高阶模型执行，逐步验收。

**目标：** 把"新开书、接管已有小说、全自动与半自动切换、冻结的旧任务继续写"统一为 `open_run`；用只读的 legacy 适配器展示旧任务；把真实入口的开关切到新内核。

**依赖：** 计划 05、07。

**设计文档：** 第 3、4、7.1、8 节。

## Global Constraints

- 继承计划 00 第 3、6 节的全部约束，但本计划允许修改现有入口，**且只能在 `open_run` 的入口处放置开关**。
- **新内核内部不得出现"新旧"分支**；开关只决定新 Run 走新内核还是旧链路。
- `legacy/` 是**只读**适配器：只能读取旧任务与旧表，不得写入；新内核（`domain/`、`application/`、`infrastructure/`、`steps/`）**不得 import `legacy/`**，方向只能是 `http → legacy`。
- **不双写**：新内核不写旧表，旧链路不写新表。
- 新旧不共用"书的当前任务"判定：新 Run 的当前判定由 `DirectorNextRunControl` 决定；旧任务只出现在历史列表中。
- 旧任务在切换时被**冻结为只读历史**，不在新引擎恢复；继续写作走接管，从小说资产（章节、卷、角色、世界观）推断起点，**不依赖旧任务的 Seed**。
- 接管默认范围是"全书前置规划接管"：先补齐缺失的规划产物，再停在生产方式选择，之后才进入正文；接管入口携带的旧章节范围或全书自动参数不得提前启动正文。
- 创作界面（阅读书架 / 完整工作台）只是显示偏好，不是权限边界，也不改变生产范围。
- 首次对真实数据运行前，必须由用户批准并完成可验证备份（`AGENTS.md` 数据保护规则）。

## Tasks（任务级）

| Task | 内容 | 验收 |
| --- | --- | --- |
| 1 | `assetInference`：读取小说业务表，为已有内容登记产物（受保护的用户内容标为 `protectedUserContent`） | 测试：已有章节正文不会被标为可覆盖；缺失的规划产物不被登记 |
| 2 | `open_run` 统一处理新开书、接管、切换、旧任务继续：关闭旧 Run、从台账起新 Run | 测试：四种来源得到相同形态的 Run；同一本书仅一个活跃 Run |
| 3 | `legacyRunProjection` | 测试：旧任务的各种状态都投影为历史；不产生任何写入（调用前后旧表所有列不变） |
| 4 | 边界测试：`legacy/` 不含任何写调用；新内核不 import `legacy/` | 测试通过 |
| 5 | 入口开关：在**真实的 `open_run` 入口处**放置按配置选择新内核或旧链路的开关，默认旧链路 | 开关关闭时行为与改动前一致；开启时只有新建 Run 走新内核，已有旧任务不受影响 |
| 6 | 切换演练（在临时库上）：准备若干处于不同状态的旧任务，打开开关，确认旧任务被冻结为历史，继续写作走接管 | 演练记录写入报告；不触碰开发库 |
