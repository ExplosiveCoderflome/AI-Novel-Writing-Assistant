# 导演 V2 全员角色时间线实施计划

**目标：** 在左侧“角色”标题下提供全员时间线入口，以角色为行、章节为列查看计划和正文出场。

**边界：** 复用已有 V2 出场检查点和章节任务，不新增模型调用、数据迁移或写库行为，不读取 V1 名字扫描记录。没有出场记录不能推断缺席。当前分支继续开发，不提交或推送。

## 1. 只读汇总

- 扩展 `shared/types/director/characterAppearances.ts`：按章节返回出场事件和计划参与者 ID，章节元信息只传一次。
- `CharacterAppearanceService` 提取共用只读投影，单角色和全员视图使用相同正文版本、计划新旧和覆盖状态规则。
- 在应用装配与 HTTP 添加 `GET /novels/:novelId/character-appearances`。一次批量读取角色、章节、计划和检查点，不按角色循环查询正文。
- 先扩展临时 SQLite 与 HTTP 测试，验证缺少汇总方法/路由导致失败；实现后验证读写隔离、V1 隔离、正文修改失效、计划最新版本和单角色结果一致。

## 2. 甘特式矩阵

- 增加 `character_timeline` 选择项，在角色组顶部显示入口；工作台独立视图使用内容区全宽。
- `appearanceModel.ts` 将全员结构化记录按角色投影，复用规划占位、章节导航和 24 章分页。
- 新建 `CastTimeline.tsx`，角色名列固定，横向滚动仅发生在图内；每格上下分别表示计划和正文，正文区分实际、提及、回忆、梦境、未核对、待写。
- 角色名打开资料；章节格打开正式章节或尚未建立正文的章节规划。无事件章节保留空白，不连接成连续出场。
- 查询沿用角色出场缓存前缀，10 秒刷新，仅视图挂载时读取一次全员汇总。错误可重试，不用空白掩盖加载失败。
- 定向测试覆盖角色隔离、非实际类型、空规划、已建章节替换规划节点、状态提示和矩阵渲染；前端类型检查。

## 3. 收尾

- 服务端构建、临时 SQLite 和 HTTP 测试、前端相关测试与类型检查。
- 更新 Wiki 的全员读取/展示边界、模块说明、README 最新更新与发布说明。
- 记录实际修改文件和验证证据到本地清单及中央 feature `director-v2-character-appearances`。
- UI 由用户验收，不自动运行浏览器、不启动真实生成。

## 实施结果

三项工作均完成。先观察前端投影缺失与全员 HTTP 404 的预期失败，再实现共用投影、汇总读取和矩阵。共享包、服务端构建与前端类型检查通过；最终前端 13 项、服务端 13 项定向测试通过，SQLite 使用新临时库。用户书的全员只读 GET 返回成功、正式章节为 0，规划占位由前端提供。文档与本地清单已同步；未提交、合并或推送，界面由用户验收。
