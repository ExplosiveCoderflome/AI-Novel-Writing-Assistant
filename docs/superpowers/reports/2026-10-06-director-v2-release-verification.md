## 隔离与数据

验证目录为独立 Git worktree；依赖按 frozen lockfile 安装。服务端验证使用 OS 临时目录中的新 SQLite 数据库和完整运行时迁移，未连接开发库、真实小说库或用户库副本。变异审计仅修改临时复制的编译文件。

V1 单元和 HTTP 测试显式提供本测试对应的持久化小说身份与任务身份；未知 ID 返回缺失。补齐身份夹具不能放宽生产环境的版本、epoch 或任务所有者检查。

## 发布闸门

当前 main 尚未合并，本地 beta 尚未推送，未创建发布标签，未上传公开安装包。继续处理剩余验证失败后更新本记录，再执行 beta → main → 匹配版本标签 → GitHub 打包发布。

按项目验证约定，页面交互与视觉验收由用户进行；本轮不自动操作浏览器，也不发起付费模型调用来补充验收。
