## 发布与资料保护

发布路径为功能分支 → beta 代码集成检查 → main → 匹配版本的 `v0.5.13` 标签 → GitHub Desktop Release。推送前从干净 main 执行仓库发布脚本 dry run；由该脚本创建标签并推送 main 与标签，另推送 beta 保持对齐。

没有执行本地 staging 或打包；GitHub 工作流在上传前运行完整类型检查、构建、迁移测试、服务端质量门与包布局验证。按仓库规则，触发后交付标签与工作流链接，不默认等待、监控或宣称安装包已发布完成。没有执行浏览器、截图、Playwright、桌面安装后 UI 验收或真实 PostgreSQL 验证；UI 验收由用户进行。

发布准备没有删除、重置、恢复、迁移用户数据库，也没有续跑旧任务。稳定知识已经写入世界设定整合、导演辅助确认与章节编辑 Wiki；本报告仅记录发布范围和证据，没有新增需要另写 Wiki 的长期规则。
