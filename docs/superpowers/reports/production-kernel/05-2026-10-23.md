## 已实现

- 最终发布：选中 accept/verify 的正式报告、问题、审校来源冲突、章节终态与 reconcile 进度 CAS 同事务。不可用检查不发布虚假分数，pending 不发布完成；正文变化、失权或报告写入异常整体回滚。
- 批次基础：持久保存一次新/旧实现绑定，旧作业保留旧路由，开关默认关闭。逐章处理器核对全部章节闭合后才生成产物；已有完成记录损坏时直接拒绝。worker 的实际 leaseOwner 显式传入步骤，不能查询新租约给旧执行者授权。
- 物理预算与原生审校重试：持久预留和实际观察，未知用量保留预留，明确未发送可释放/重新预留，迟到用量仍记账。取消/失权后只记已经发生的事实。初审/候选共用持久重试计数，并串接外层物理预约；存储异常锁存，不能被兼容降级吞成成功。
- 安全恢复：明确未发送的拒绝才解除领取，保留 deferredDescriptor；恢复使用同一完整输入。模型检查点缺失/ready 与 running 未知分开，恢复读取不发模型。前序消费者修改账本也不会触发重复抽取。
- 兼容与合同：已有非空正文原样复用，空草稿不额外重试；QualityDebt/StopSignal 迁入共用合同，原始债务封套保持无损。十组差异报告更新批准状态和源码指纹，独立兼容恢复用例未混入十组观察数。
- 原生只读预检：在批准范围隔离审校/补丁请求字段，与真实原生服务捕获到的注册请求逐字段对照。正式覆盖、模板、上下文选择和结构化提示共用只读渲染；完整正文、修复基线、写法保护均保留，预检不调用模型。
- 模型配置与预算：执行前核对主模型、备用模型、协议策略及纠错配置，错误锁存不能被原生兼容处理吞成成功。每次物理请求按当前完整消息、响应格式、工具、模型构造参数及输出上限预约；JSON 纠错附加报告后使用更大的预约。窗口仅接受明确 provider/model 元数据，未知窗口或原生省略可执行输出上限时拒绝；没有为真实模型猜窗口或改写用户配置。
- 正式阶段能力：writer、初审、候选事实核对、补丁均有保存请求的预检/执行检查；补丁使用预检时保存的 runtime 许可。该能力尚未由 productionComposition 安装到完整原生生产链。
- 来源页读取接线：批次修订确认与进度读取按持久新旧绑定识别内核，核对真实完成回执，不虚构 GenerationJob。当前阶段来自单章领取，暂停时隐藏运行阶段；人工改稿使旧完成事实失效。读取不确认质量暂停或恢复任务。
