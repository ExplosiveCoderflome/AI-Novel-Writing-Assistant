# 计划 04：共用约定与工具本地验收

状态：本地完成并自验，尚未替换长篇/短篇调用方，未合入 beta/main。

## 产物

`modules/production/common/` 拥有唯一 facade、README 与六类职责：

- 安全补丁：全部锚点在同一原文定位，校验唯一和重叠后倒序应用；失败返回完整原文，不泄漏部分结果。
- JSON 数据：完整复制并稳定排序；拒绝 undefined、非有限数字、循环及类对象，不能悄悄丢掉来源证据。
- 质量债与停止：保存长篇原始根因/义务/归因/尝试及短篇原始字符串；只消费结构化停止范围与人工暂停，不解释文本语义。
- 编辑围栏：自动写入保护人工编辑；仓储回调负责把正文版本、编辑基线与持久所有权放在原子 CAS 内；冲突不重试覆盖。
- 上下文预算：完整输入估算 + 输出 + 安全余量；默认 UTF-8 字节保守估算，可注入 tokenizer 计数；未知窗口明确失败。
- 预算/用量合同：持久预约先于请求；拒绝不调用模型。已发生用量在取消/失权后仍可记录，未知数字保留 null，sink 按 invocationId 去重。

## 验证

28 项 common 测试通过，包含成功、不唯一、缺失、交叉/嵌套/重复补丁、相邻替换再次成为锚点、无变化、删除、整批回退；债务无损 roundtrip；局部继续/全局停止/人工暂停；围栏冲突；输入预算边界与非法值；预约拒绝及失败用量。

AST 边界检查通过：common 只导入自己的文件，无 IO、时钟或随机调用；单文件不超过 400 行；SQLite 测试已注册 integration。common 不依赖 domain/application/infrastructure 或短篇。

完整服务端构建通过；生产范围总计 101 项回归通过。重叠、预约、局部停止三项破坏变异分别触发 3、2、1 项失败；相关编译文件未修改。正文/进度 CAS 的真实事务验收属于 03 报告，不将 common 的 fake 回调当作数据库证明。
