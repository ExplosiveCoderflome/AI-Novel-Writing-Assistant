## 发布路径与限制

功能分支 → beta 验证 → main → `v0.5.15` 标签 → GitHub Desktop Release。main 与 beta 使用快进对齐，不强制推送；从干净 main 执行仓库发布脚本 dry run 后再推送标签。完成集成后清理本次功能分支，不清理其他历史工作区或分支。

GitHub 工作流在公开上传前执行类型检查、构建、迁移检查、服务端质量门及包布局验证。本轮不执行本地打包，触发后交付标签及工作流链接，不默认轮询结果。本报告不作为安装包发布完成的证据。

本轮使用新建临时 SQLite 和确定性模型替身验证调度故障，没有修改用户数据库或 API 配置，没有付费模型调用，没有重新生成 12 章，也没有浏览器或新安装包界面验收。界面由用户验收。#195 原始“选择方案后立即停止”的具体触发原因仍缺日志，不据此关闭 Issue。
