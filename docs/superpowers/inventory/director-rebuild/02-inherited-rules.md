## 发现的问题与冲突

- R07 / R08 必须解释为完成优先下的默认规则，不能覆盖 R09 的质量优先暂停。执行证据：`server/src/services/novel/production/qualityClosure/ChapterQualityClosure.ts:50`，规范证据：`docs/wiki/workflows/auto-director-runtime.md:106`。
- R15 与设计恢复提案冲突。当前章节 runtime 在服务重启后要求人工恢复；租约过期可以根据任务策略尝试恢复，但已有人工恢复锁必须保留。来源：`server/src/services/novel/NovelPipelineRuntimeService.ts:45`、`server/src/services/novel/director/commands/leases/DirectorCommandLeaseService.ts:73`、`docs/superpowers/specs/2026-09-30-director-rebuild-design.md:273`。
- R17 的预取失败条款与 R19 的展示偏好边界仅有规范依据，不能写成存在具体实现。它们保留为设计要求，前者要在步骤适配时确认真实触点，后者只能约束投影，不能派生权限。来源：`docs/wiki/workflows/lazy-chapter-planning.md:18`、`docs/wiki/workflows/auto-director-runtime.md:34`。
- 策略冻结、范围、模型选择和计划版本需要在 RunContract 中明确保存，后续 Worker 不得读取全局设置覆盖它们。现有任务快照读取证据：`server/src/services/novel/director/issues/DirectorIssueTaskContext.ts:29`；原设计合同：`docs/superpowers/specs/2026-09-30-director-rebuild-design.md:63`。
