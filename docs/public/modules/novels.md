# 小说列表

小说列表用于创建、打开、管理、导出和恢复小说项目。它提供三种开书依据：一句灵感、热门题材和已完成拆书。

![小说列表界面截图](../../../images/v2/微信截图_20260813220328.png)

## 适合什么时候打开

- 创建一本新小说。
- 从热门题材或参考小说发起自动导演开书。
- 回到已有小说继续创作。
- 查看每本小说的基础信息和最近状态。
- 管理测试项目、归档项目或备份内容。
- 从项目维度进入创作中枢、导演跟进和章节流程。

如果你明确知道要继续哪本书，从小说列表进入最直接。

## 三种开书入口

| 你手上有什么 | 推荐入口 | 系统会先做什么 |
| --- | --- | --- |
| 一句想法 | AI 自动导演开书 | 整理题材、卖点、读者感受和整本方向 |
| 还没有想法 | 热门题材雷达 | 从公开榜单提炼可核对的市场信号 |
| 一份完成的拆书 | 照着一本书写 | 选择续写原作或参考创作新书，并带入拆书结论 |
| 已有完整设定 | 手动创建小说 | 直接填写项目资料，再进入专业工作台 |

第一次使用时，优先选择前三种入口，让系统先提供方向和默认值。手动创建更适合已经明确掌握书级设定的用户。

## 照着一本书写

小说列表和自动导演起始页都提供“照着一本书写”。使用前需要至少一份状态为成功的拆书结果。

1. 点击“照着一本书写”。
2. 选择一份参考小说拆书。
3. 选择“续写原作”或“参考创作新书”。
4. 进入自动导演开书页，核对已带入的拆书结论、写法和基础设置。
5. 继续生成方向候选并确认新项目。

| 创作方式 | 会保留什么 | 会重新生成什么 |
| --- | --- | --- |
| 续写原作 | 角色、世界规则、时间线和未完线索 | 原作结尾之后的新情节与章节 |
| 参考创作新书 | 结构、节奏和写法经验 | 角色、世界、剧情和项目事实 |

参考创作不会把原作人物和事实当作新书设定。参考写法会在后台准备；写法暂时不可用时，开书流程仍可继续。

## 创建小说

创建小说时，不必一次填满全部设定。新手建议先准备：

- 书名或临时标题。
- 一句核心灵感。
- 目标题材或读者感受。
- 简短主角方向。

系统后续可以通过自动导演继续扩展世界、角色、卷结构和章节任务。标题也可以先用临时名称，等标题工坊生成候选后再调整。

## 简易创作和专业创作

项目创建后可以进入两种创作界面：

- 简易创作：以书架、正文阅读、进度和推荐下一步为主，适合让自动导演持续完成整本书。
- 专业创作：展示项目设定、故事宏观、角色、卷战略、拆章、章节执行和质量修复，适合检查与调整完整链路。

两种界面共享同一套正文、审校、恢复、编辑和导出数据。切换界面不会重新创建项目，也不会要求从头生成章节。

## 列表字段怎么看

列表通常会展示这些信息：

- 小说名称：识别项目。
- 最近更新时间：判断哪个项目刚被推进过。
- 创作状态：了解是否处在准备、执行、暂停或完成阶段。
- 任务入口：回到创作中枢、导演跟进或章节链。
- 管理操作：打开、编辑基础信息、删除或导出。

专业创作的“导出”可以按章节顺序下载整本 TXT 正文；项目资产仍可使用 Markdown 或 JSON 导出。

如果列表中看不出任务是否还在跑，进入任务中心确认后台状态。

## 打开小说后先看什么

打开一本小说后，建议按顺序看：

1. 基础信息是否完整。
2. 自动导演是否有等待确认项。
3. 章节计划是否准备好。
4. 最近章节是否有质量债务或修复建议。
5. 任务中心是否有运行中任务。

这样可以避免在错误入口重复发起生成。

## 删除和备份

删除小说前请确认有备份。重要小说建议至少保留：

- 小说导出文本。
- 数据库备份。
- 关键设定、角色和世界资料。
- 知识库资料源文件。

不要把删除当作排查问题的第一选择。遇到状态异常时，先查看任务中心、导演跟进和故障排查文档。

## 测试项目管理

使用新模型、新提示词或新知识库设置时，建议创建测试小说验证。测试项目命名可以带上目的，例如“测试-知识库召回”或“测试-正文模型”。

测试完成后再把稳定配置用于正式小说，能减少重要项目被错误设置影响的风险。

## 和主链的关系

小说列表负责项目入口；热门题材雷达和拆书提供开书依据；创作中枢负责查询状态和诊断问题；自动导演负责推进准备；章节链负责生成正文；运行记录负责后台状态。

当你不知道某本书停在哪里时，先从小说列表打开项目，再看导演跟进和任务中心。
