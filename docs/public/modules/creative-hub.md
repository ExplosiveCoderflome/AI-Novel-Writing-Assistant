# 创作中枢

创作中枢是面向整个创作过程的状态查询与问题诊断入口。它帮助你看懂当前小说进度、解释执行记录、定位失败原因，并把需要实际操作的事项带到正确的正式工作台。

![创作中枢界面截图](../../../images/创作中枢.png)

## 它能做什么

- 查询小说、章节、世界观、角色和整本进度。
- 查看任务、导演运行记录和失败原因。
- 分析手动改文可能影响的范围。
- 解释当前状态与下一步建议。
- 导航到小说工作台、AI 自动导演、章节页、运行记录或模型设置。

创作中枢不会创建小说、生成世界观或角色、写作或保存正文，也不会启动整本流水线、继续导演、恢复、重试、取消或审批写入。

## 什么时候使用

你可以直接询问：

- “这本书现在写到哪一步了？”
- “自动导演为什么停在这里？”
- “第三章失败的原因是什么？”
- “我改了第三章，后面哪些内容可能受影响？”
- “这项操作应该从哪里进入？”

需要创建、生成、写作、保存或恢复时，创作中枢会给出对应来源页面的正式入口链接。小说产物以对应工作台为准，后台任务状态可在运行记录查询。

## 与正式工作台的关系

| 需求 | 推荐入口 |
| --- | --- |
| 创建小说、补齐开书信息 | 小说工作台 |
| 生成世界观、角色、大纲和章节规划 | 小说工作台 / AI 自动导演 |
| 写作、重写和保存正文 | 章节工作台 |
| 继续、恢复、重试、取消导演任务 | AI 自动导演或任务来源页面 |
| 查询状态、诊断问题、查看执行记录 | 创作中枢 |
| 调整模型和厂商 | 模型设置 |

创作中枢只读取结构化状态，不把查询过程写入导演任务分析记录，也不会用“预览”替代正式执行。

## 遇到卡住怎么办

先询问当前状态和失败原因，再按照建议进入对应模块。运行记录只用于查看后台状态、错误与来源；真正的创作动作仍在小说工作台、自动导演和章节页面中完成。

## 提问模板

| 目标 | 示例 |
| --- | --- |
| 查询进度 | “当前已经完成几章？” |
| 诊断问题 | “为什么世界观准备还是待推进？” |
| 查看记录 | “列出这本书最近的执行任务。” |
| 影响分析 | “我手动改了主角动机，会影响哪些章节？” |
| 找入口 | “我要继续自动导演，应该去哪里？” |
