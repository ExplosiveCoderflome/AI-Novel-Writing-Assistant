# 自动导演台与运行记录的展示边界

## Background

自动导演会跨越规划、资产准备和正文批次。新手需要在小说上下文中知道 AI 正在做什么，以及自己是否需要操作；历史运行记录则只负责追溯事实。把两者放在同一张任务操作页，会让用户离开创作现场，也会把暂停、质量提醒和失败混成一个问题。

## Decision

- 小说导演台采用“目录工作台”：左侧小说资源目录，中间资料摘要或正文阅读，右侧可收起的导演台。入口为 `/lab/director/:novelId`；窄屏目录可折叠，导演信息在正文后展示。
- `/lab/director` 是跨书运行记录，只读展示状态、进度、错误、来源路由和需要处理筛选，不承载继续、恢复、取消、重试或重规划。
- 导演台的展示模型只消费后端 `DashboardView`，固定分为“正在做什么 / 需要你做什么 / 质量债 / 时间线”，诊断信息折叠展示。
- 主按钮只能来自 `availableActions` 中标记为主动作的结构化动作；`navigate` 只跳转到来源页，`command` 只在小说导演台提交。
- 顶部同时展示当前创作方式和运行状态：`driver=auto` 为“全自动推进”，`driver=assisted` 为“按阶段确认（半自动）”。暂停、等待确认和完成属于运行状态，不能用来推断创作方式；方式也不能只藏在诊断信息中。切换按钮表示可切换的目标，顶部标识始终使用当前投影方式，保持窄栏可换行。

## Current Rule

书架卡片、继续创作卡片和项目卡片使用后端的 `workspaceSourceRoute` 进入本书导演台。新导演启用时，长篇的入口由应用装配提供；短篇保持连续作品入口。前端只接受当前小说的精确来源地址，不接受其他小说或外部链接。这个字段只决定导航，不改变持久化创作方式，也不是正文生成或恢复授权。

有新来源地址时，书架不以旧开书任务的成功状态或百分比展示本书创作进度，不提供旧继续命令及旧驾驶舱操作。进入本书导演台后再由 DashboardView 展示运行事实、确认和授权范围。正文编辑、阅读预览和封面操作须保持功能目的明确，不能暗中启动旧编排。

DashboardView 的主状态展示只属于 components/directorNext 下的 DirectorBadge 与 DirectorPanel。页面可以传递投影，但不能用变量改名、展开、下标或解构另行推断状态。代码守卫通过 TypeScript 类型来源核对这一边界，历史记录 DTO 的展示字段不属于 DashboardView；未知 any 类型不能绕过检查。允许路径须精确匹配，仿冒文件名不取得展示权限。变异验证只修改临时源副本，并保持类型依赖一致，避免把依赖缺失的错误当作边界验证成功。

运行记录页面不得根据原始运行字段推断主状态，也不得放置改变任务状态的按钮。来源页负责展示动作的影响范围，并在命令提交后刷新导演台摘要和详情。

### 阅读与角色动态

初学者应在读正文时理解角色变化，不必跳到复杂的角色管理页。正文旁提供本书角色快捷入口，抽屉展示有章节来源的变化记录；入口不宣称人物一定在本章出场。角色的全书设定与已发生的变化分开展示。

默认“读到本章”只展示阅读章节及以前的记录，缺少章节顺序的记录不进入该范围。没有记录必须说明缺口，不用静态性格或最新状态冒充历史。现有动态总览虽然接受章节参数，其人物状态、目标等仍读取可变最新字段，因此仅在读者显式选择“最新状态”后使用，并说明可能剧透、无逐章历史快照。

资源轮询更新目录，不自动跳到最新章节。同章正文更新保留读者打开的版本，读者可主动加载；打开角色抽屉不卸载阅读器，关闭后保留阅读位置。资产查询和导演查询独立失败，导演服务不可用也不应遮挡保存的正文。

目录使用书架接口的故事约定、世界/角色摘要和保存正文，以及完整卷工作区的卷纲、节奏段和章节规划。完整宏观规划及全部资产字段编辑仍在小说编辑工作区，浏览能力不能标为资产编辑能力。

### 单一本书目录与规划关联

导演工作台隐藏常驻全局侧栏，保留顶部全局菜单和返回书架入口，离开工作台恢复原导航。全局侧栏与本书目录同时常驻会挤压正文，也让新手难以区分产品模块和本书内容。

故事目录按卷、节奏段、章节组织；卷来源为完整卷工作区，不以只含摘要的书架列表截断规划。卷内章节通过保存的 `beatKey` 关联节奏段；正文优先通过 `chapterId` 关联，只有缺少该 ID 时才通过同书 `chapterOrder` 关联。已存在但失效的 ID 不按序号替代，避免读到另一个章节。`chapterSpanHint` 是规划提示，禁止据此猜测归属。

未关联节奏段的规划、未关联卷规划的正文需要保留“待归类章节”入口。无正文的章节规划展示“待写正文”，不能因没有正文隐藏它，也不能当成已完成章节。卷和节奏段详情展示目标及所属章节，正文顶部提供可返回的归属导航与折叠的本章目标。

## Failure Modes

- 把运行记录做成恢复工作台：检查页面是否出现继续、恢复、重试、取消或重规划按钮。
- 前端根据 `status`、`pause` 或 `cursorStepId` 猜测主按钮：应改为读取 `DashboardView` 的 `headline`、`mode`、`progress` 和 `availableActions`。
- 移动端仍保持桌面侧栏：导演台应在窄屏变为完整宽度的连续信息段，保证新手能读懂当前动作和下一步。
