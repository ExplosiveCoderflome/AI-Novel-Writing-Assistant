# 章节与记忆的模型输出额度

章节任务单同时生成执行目标、任务和场景卡。调用端固定较小的输出额度，会截断原本能在规划模型额度内完成的结构化结果。

- 章节执行合同使用 `planner` 路由，由模型工厂结合路由配置、默认额度和端点能力计算实际申请值。
- 章节任务单的质量修订沿用同一任务额度。进入第二次生成前检查取消信号，避免作者停止任务后仍发出模型请求。
- 已启动的自动导演任务通过 `TaskOutputBudget` 使用冻结的输出额度，恢复后沿用原任务配置。
- 章节记忆和原生结构纠错共用 `fact_extraction` 路由的有效额度。两者都需要完整校验输出后才能保存记忆。
