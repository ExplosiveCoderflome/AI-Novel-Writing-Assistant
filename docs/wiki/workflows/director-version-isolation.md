# 导演 V1 / V2 归属与隔离

## 背景与决定

导演版本与全自动、按阶段确认是两个选择。用户按小说选择 V1 或 V2；两套编排保持独立，仅共用已保存的创作资产及底层章节生产能力。环境开关控制 V2 可用性，不能把 V1 小说或任务改成 V2。

## 当前规则

- `Novel.directorVersion` 显式绑定优先。未绑定的历史长篇存在 V2 Run 时识别为 V2，其余识别为 V1；读取不得回填数据。短篇不参与导演版本选择。
- 小说维护 `directorEpoch`。V1 工作流冻结 `directorVersion` 和 `directorEpoch`；V2 将通用 `executionEpoch` 冻结在不可变 Run 契约。缺失的历史 epoch 仅兼容为 0。
- 切换使用事务锁定小说行和期望 epoch。当前流程的任务、确认门、人工暂停、正文作业或有效执行租约未结束时拒绝切换。切换仅保存目标版本并递增 epoch，不调用模型、不创建生产任务。
- V1 已接受但仍排队的命令也属于未结束生产，即使任务展示为终态仍禁止切换。否则版本事务可能在 Worker 读取权限与领取租约之间完成，造成跨代次领取。
- 切回同一版本也不能恢复旧 epoch。原任务的 Seed、游标、门、质量债和正文作业不转译；在目标工作台由用户明确授权后开始新任务。
- V2 不可用时保留本书 V2 身份，不将它交给 V1。开书页只显示可用版本，新书优先 V2；候选任务一旦建立，所选版本冻结。
- 未绑定小说、未保存版本的历史候选任务按 V1 冻结。后续请求不能用新版本参数改写该任务，必须新建所选版本的候选任务。

## 执行与恢复边界

V1 HTTP、Agent 缓存工具、通知回调、命令接收、租约领取、陈旧修复和启动恢复均核验所属版本及 epoch。V2 通过 app 层注入的通用执行端口核验，内核不得导入 V1、版本路由模块或业务生成服务。

两套 Worker 在同一服务中运行，各自只领取合法身份的任务。过滤必须发生在租约和状态写入前；V2 队列按稳定顺序分页，不能让一批过期身份占住队列前端。执行前再次核验，不能只依赖按钮或规划工具目录。

共享正文作业必须仅有一个所有者：V1 `workflowTaskId` 或 V2 `directorNext.runId`。同时出现两种身份、跨书身份或过期 epoch 必须在状态及正文写入前拒绝。V1 watchdog、启动恢复及取消巡检跳过 V2 作业。V2 通过绑定自己的 Run 的显式恢复事务继续原作业。

相同章节范围的作业查询只读。去重只允许发生在明确授权的启动路径，且所有被处理作业必须属于同一任务；不得取消、重排或采用另一流程的作业。

正文启动和 V1 自动执行按完整所有者查询活跃作业；恢复复用必须再次比对请求所有者与持久化所有者。通用 V1 重试和取消入口拒绝 V2 作业，不能丢弃 V2 所有者后新建手动作业。没有所有者参数的范围查询仅用于读取，不授予恢复权限。

V2 开书适配器复用候选服务，仅执行已接受的指定候选命令 ID；持久化版本在首次创建任务时写入。V1 队列不会领取 V2 候选命令。方向确认后分别交给 V1 工作流或 V2 Run，开书准备不代表正文生产完成。

## 导航与显示

书架、详情、顶部版本标识和恢复来源由小说当前归属决定。V1 返回原工作台，V2 返回新导演台。版本选择成功后刷新查询缓存并导航，不发起生成。

旧 current、book-automation 和 auto-director 查询对 V1 保留原行为；对 V2 在进入旧投影前返回空当前态和 V2 来源。V2 当前查询只选当前 epoch 的 Run，旧版本的历史状态不能冒充当前创作。历史记录仍只读保留其原始事实，过期身份不能通过恢复操作复活。

“运行记录”只提供阅读和来源导航。恢复、取消和版本切换在能看到本书上下文的工作台操作。

世界地图与角色关系图可以复用纯展示组件和只读资产查询。筛选、布局或打开图谱不调用旧导演、不触发 AI 生成；详细边界见[导演资产图谱](director-asset-visualizations.md)。

## 验证与迁移

使用完整 schema 的独立临时 SQLite 演练真实 app 挂载顺序，覆盖跨版本零写入、切换并发、旧 epoch 围栏、双 Worker 租约、开书冻结以及 V1 watchdog 不修改 V2 作业。将旧任务所有列和已保存正文做快照比较。纯单元测试显式提供身份夹具，不连接开发数据库。

两种数据库的增量迁移只新增小说和 V1 工作流的四个字段。真实库应用前保存可验证备份；历史已通过 schema 同步建表而迁移账本不全的 SQLite，不能盲目重跑全部迁移。仅执行经核验的新增字段 SQL，记录对应迁移，保留旧账本、内容及状态。

## 相关模块

- `server/src/modules/novel/director-routing/`：归属、epoch、安全切换和正文所有者验证。
- `server/src/app/director/`：入口装配、开书交接与 V2 业务端口。
- `server/src/modules/director/`：独立 V2 契约、台账、状态机和 Worker。
- `server/src/services/novel/director/`：V1 独立命令、状态与执行。
- `client/src/components/directorVersion/`：版本显示、选择与来源导航。
