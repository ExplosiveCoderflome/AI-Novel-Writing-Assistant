# 导演入口、接管与历史边界

## 背景与决定

用户的小说内容是创作的事实来源。历史任务的启动输入可能过期或缺失，不能决定接管起点。新导演先读取业务表和已保存版本，补齐规划；正文由用户另行授权章节范围。

## 当前规则

- 开关 `DIRECTOR_NEXT_ENABLED` 默认关闭，在应用入口装配新 HTTP 门面、生产处理器及 Worker。配置切换需要重启服务，新内核不判断历史任务来源。
- 启用时历史导演命令入口拒绝写入，提供小说来源路由；旧导演 Worker、旧正文恢复初始化及其自动恢复 watchdog 不启动。其他恢复服务保持自身职责。历史表不通过“冻结”写回状态或迁移 Seed。
- 历史投影只读旧任务的标题、状态、进度和错误，固定为历史，只提供来源导航。历史任务不会变成新 Run 的控制行。
- 创作工作室确认长篇方向时，入口适配器创建小说业务记录，使用已选模型启动新 Run；默认仅规划并采用阶段确认。用户选择正文范围前不能启动正文。
- 开书使用确认记录推导稳定内部小说 id，重复提交复用小说及命令。HTTP 小说创建 schema 不接受内部 id。创建与 Run 启动之间发生中断，可从同一小说重试，不创建第二本书。
- 接管读取故事规划、创作约定、关联世界、角色、卷版本、章节路线和已保存正文。只登记实际存在的内容；不完整但有内容的规划过期且受保护，不能被当成空白覆盖。
- 正文逐章登记保护范围，已有未收尾正文不能进入自动重写范围。正文生成作业仍负责跳过当前内容已完成的章节。
- 批次 scope 包含授权起止章节，指定卷也参与 scope。不同范围的“批次已完成”不能满足新的批次；切换模式保留原 scope 和模型、策略、范围快照。
- 新工作台的内容读取不读取历史任务 Seed，不触发兼容数据补写，角色目录不设旧书架的展示数量上限。
- 运行记录只读；启动、确认、恢复、取消与模式切换均在小说导演台进行。

## 恢复与停止

人工暂停只能由显式恢复命令解除。明确重规划的正文作业需先保存晚于暂停时间的卷路线；恢复清除当前停止信号，并保留问题历史及已处理游标。取消只请求停止归属该 Run 的作业，不能取消其他创作或清空正文。

切换方式必须在保存边界；未收尾的正文批次不允许通过换模式绕过恢复。Worker 的失败额度在显式恢复后重新计数，累计 Token 授权不重置。

租约拥有者可以继续领取自身的运行中 Run；其他 Worker 仍需等待租约过期。不能仅查询过期租约，否则每个保存边界都会产生一次租约时长的无效等待。等待确认的 Run 不参与 Worker 领取，避免占用候选名额。

## 验证与投放边界

临时 SQLite 演练创建完整业务 schema，覆盖新开书、已有小说接管、切换、历史投影及默认规划范围；检查旧任务所有列、正文、台账与同书单活跃约束。前端使用类型及投影契约检查，交互和视觉由用户验收。

真实数据首次启用前需明确授权和可验证备份。计划 09 的旧引擎删除还要求 01～08 验收、beta 稳定一个发布周期及单独批准；入口切换不等于满足删除条件。

## 创作空间与运行权限

书架和首页的长篇开书入口使用 `/create?form=long_novel`，通过创作工作室确认方向后进入新导演。旧 `/novels/auto-director?taskId=...` 可读取历史，但其命令入口不能继续运行旧任务。拦截响应必须提供可操作的来源路由：已关联小说的任务回到该小说导演台，尚未建书的任务进入长篇创作入口；不能只返回一段没有导航的说明。旧任务不得自动转换或恢复。

目录、正文和导演台的宽度由用户通过分隔线分配，宽度偏好仅保存在浏览器。这样阅读较长的规划、正文或导演表单时可以扩展对应区域，而不需要切换生产方式。布局调整和收起辅助区均不能改变章节授权范围、确认门或运行模式；窄屏按实际容器宽度上下排列。组件由 `components/layout/resizableWorkspace` 承载，设计约束见 `docs/design/product-ui-design-system.md`。

## 相关模块

- `app/director/`：入口装配、业务资产读取、新书交接、业务作业控制。
- `modules/director/application/assetInference.ts`：纯资产保护登记。
- `modules/director/legacy/`：只读历史投影；只能由 HTTP 层使用。
- `components/directorNext/`：导演状态、授权表单与来源操作。

这些边界影响开书、章节生产、恢复及前端投影，不改变 Prompt 注册和 AI 质量判断算法。
