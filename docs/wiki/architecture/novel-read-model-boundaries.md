# 小说目录与导演事实的只读边界

## 背景

小说目录和导演事实摘要用于展示已保存结果。若读取故障被替换成 `null` 或空集合，投影会把数据库不可用误判为未完成规划、没有角色或没有章节，进而误导后续步骤判断。若查询复用带自动回填的读取方法，仅浏览结果也可能改变规划状态。

## 当前规则

- 小说目录由 `services/novel/catalog` 入口提供，拥有筛选、分页和关联摘要，不执行恢复或写命令。
- 导演 `DirectorFactReader` 读取成功且缺少记录时才返回空事实。数据库失败向上传播，摘要不能以“空事实”继续完成计算。
- 分卷投影使用 `volume/read-model` 入口。兼容活动卷、版本和旧大纲时仅构造内存文档，不激活版本、不补写卷行、不同步执行字段。
- 分卷命令服务可以恢复和保存规划工作区；这一行为不能进入事实读取链。章节执行事实从章节进度检查器读取。
- 目录最新任务仍保留失败、阻塞和等待恢复状态；排除归档后按更新时间及 ID 选择。活动步骤标签仅用于补充展示，不能修正任务状态。

## 影响范围与故障诊断

规则覆盖小说目录、导演步骤事实摘要与任务事实检查。只读失败应由请求或工作流既有错误边界处理，不能通过伪造缺失结果触发重新生成或写入恢复。诊断时先区分真实缺失和读取异常，再检查持久化动作是否经过显式命令入口。
