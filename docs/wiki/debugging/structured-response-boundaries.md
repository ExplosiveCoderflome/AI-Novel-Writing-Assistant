# 结构化响应、任务预算和安全排障

## 背景

结构化失败可能来自传输、输出上限、JSON 语法、schema 合同或后续业务语义。将解析失败代入 `null` 后继续校验，或把 `repair_done` 当成校验成功，会让用户换模型后仍得到相似但误导的错误。

## 当前规则

- 零次修复必须保留解析失败，不能制造空对象或 `null` 代替响应。超量、缺项和重复章节应拒绝，不能裁剪数据获得成功。
- 最终正文与推理在共享响应读取器中分离。字符串里的反引号和思考标签必须保留；流的结束原因与用量不能在拼接时丢弃。
- 结构化输出出现显式长度终止时，不在同一额度下重复修复或格式降级。章节任务将一个大节奏段按明确的输出预算拆成顺序批次，未配置时从八章开始；仅长度/不完整问题允许有限减半，单项失败必须返回错误。每批数量、节奏段、跨批标题和最终总数仍要校验。
- 全文写法提取按来源顺序分段，不裁掉原文。未配置能力时每段最多 24,000 字符；配置了能力后按可用输入预算调整，保留每段的有效特征及证据，合并时为特征 ID 加片段前缀。任一片段失败不能生成“全部成功”的写法。
- 输入预算覆盖最终渲染消息、内联来源和原生 response schema，并预留输出与安全余量。估算使用 UTF-8 字节数，是近似的本地预检，不等于供应商真实 tokenizer。未知端点不虚构硬窗口。只有用户配置的上下文/输入能力或环境保护值会形成预算限制；明确共享输入输出窗口时只预留一次总输出，思考容量备注不与输出相加。不得自动删掉用户内容或必需上下文来满足预算。
- 中文长文、结构合同和输出预算必须一起观察；上下文块的预算不代表完整请求用量。

## 验证与隐私

修复请求保留完整来源，不摘掉中间段落；无法无损修正的内容应失败，不能让模型补造事实通过结构校验。

修复响应的唯一顶层键为非空字符串 `repair_error` 且不符合目标业务 schema 时，表示明确拒绝无损修复，不是业务字段同时丢失。保留最初的语法/结构错误、原始字段路径和修复终止元数据；立即停止后续格式修复、协议降级及备用模型尝试。模型给出的拒绝原文属于不可信内容，不进入默认错误日志。目标 schema 本身合法接受 `repair_error` 时仍按正常业务结果处理。

宏观规划的 JSON 输出合同由规范 schema 导出，随 `novel.story_macro.decomposition@v3` 在消息构造末端加入，普通提示和高级模板都必须收到完整必填项、文字长度与数组数量限制；不能因为已有手写 JSON 示例而跳过合同。该变更不放宽业务 schema，也不修改模型保存的上下文或输出设置。初次 schema 失败记录有界的字段路径和错误代码，不记录正文；临时诊断快照会过期，缺少原始输出时不得从后续修复错误倒推最初违约字段。

回归使用合成 JSON、跨块思考标签、真实 SDK 的本机 SSE mock、截断批次、完整合并和请求次数断言，不需要付费模型。

生产诊断记录结构信息和用量，默认不保存完整修复提示词及响应。密钥和正文不得放入测试、提交或诊断报告。真实模型验收需要明确样本、成本上限和数据范围。

## 模型设置与接口合同

输出优先级：本次明确指定 > 任务明确设置 > 模型手动设置 > 该功能原默认值 > 原 provider 默认行为。历史自动保存的 4096 哨兵不覆盖模型设置；新明确填写的 4096 保留。只验证正安全整数，不按模型名称强行缩小额度，也不把能力上限自动设为请求默认。

接口优先级：本次或任务明确选择 > 模型选择 > 已知官方主机的协议 > 通用 Chat。通用兼容端点不因模型别名继承厂商思考扩展。上下文、最大输入、总生成输出、思考能力备注和本次思考控制各自保存；Claude 固定预算、Gemini 预算/强度与 OpenAI/DeepSeek 强度依接口验证，不相加制造容量。模型拒绝的参数应报告 HTTP 状态，不能静默删除参数重试。

锁定的 SDK 会按模型名重写 Chat 输出字段，并忽略部分 Responses 终止控制。因此在同源传输边界中规范请求字段、检查 SSE 完整结束，显式截断在 SDK 吞掉事件之前被分类。默认关闭 SDK 自动重试，产品重试与章节减半都有预算上限。

模型发现按接口认证，支持 Gemini pageToken 和 Claude after_id 分页。跨域下一页、分页循环和保护范围超限报错；手动模型 ID 始终可保留。API 凭据不跟随重定向或跨 origin 的模型链接。
