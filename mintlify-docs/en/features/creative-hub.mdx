The Creative Hub is a status query and problem diagnosis entry point for the entire creative process. It helps you understand current novel progress, interpret execution records, locate failure causes, and direct actionable items to the correct formal workbenches.

## What It Can Do

- Query novel, chapter, worldview, character, and whole-book progress.
- View tasks, director run records, and failure causes.
- Analyze the scope potentially affected by manual text revisions.
- Explain current status and next-step recommendations.
- Navigate to the novel workbench, AI Auto Director, chapter page, Run History, or model settings.

The Creative Hub does not create novels, generate worldviews or characters, write or save prose, nor start whole-book pipelines, continue directing, resume, retry, cancel, or approve writes.

## When to Use It

You can directly ask:

- "What step is this book at now?"
- "Why did Auto Director stop here?"
- "What is the reason Chapter 3 failed?"
- "I revised Chapter 3; which later content might be affected?"
- "Which page should I enter for this operation?"

When creation, generation, writing, saving, or resuming is needed, the Creative Hub will provide the corresponding source page's formal entry link. Novel artifacts are authoritative in their respective workbenches; backend task status can be queried in Run History.

## Relationship with Formal Workbenches

| Need | Recommended Entry |
| --- | --- |
| Create a novel, complete book-starting info | Novel workbench |
| Generate worldview, characters, outline, and chapter planning | Novel workbench / AI Auto Director |
| Write, rewrite, and save prose | Chapter workbench |
| Continue, resume, retry, or cancel director tasks | AI Auto Director or the task source page |
| Query status, diagnose problems, view execution records | Creative Hub |
| Adjust models and vendors | Model settings |

The Creative Hub only reads structured status. It does not write the query process into director task analysis records, nor does it use "preview" to replace formal execution.

## What to Do When Stuck

First ask about current status and failure cause, then follow recommendations to enter the corresponding module. Run History is only for viewing backend status, errors, and sources; actual creative actions are still completed in the novel workbench, Auto Director, and chapter pages.
