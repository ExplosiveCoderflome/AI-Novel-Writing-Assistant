The base Character Library is used to save reusable character assets. It is suitable for accumulating stable character settings, appearance, identity, personality, abilities, relationship foundations, and reference images, which can later be imported into specific novels to continue using.

<Note>
  The base Character Library saves long-term reusable character assets, not the "plot status" of a specific book. After importing into a novel, the character's current status can be adjusted separately according to the book's world and plot goals.
</Note>

## What the Character Library Can Do for You

- Save long-term reusable characters, rather than characters that only exist in a single book.
- Precipitate stable character assets from novel characters or book breakdown characters.
- Manage character base images, main images, and candidate images.
- Import existing characters into new novels to reduce repeated creation.
- Distinguish between a character's "stable assets" and the "plot status" in a specific book.

## When to Use It

- You have commonly used protagonists, supporting characters, villains, or character archetypes.
- You want to upgrade characters researched from book breakdown into reusable materials.
- You want multiple projects to share the same type of character settings.
- You want to maintain character reference images to ensure more consistent subsequent visual generation.
- You want to organize a character's identity tags, stance, abilities, taboo miswriting items, and other long-term information.

## Preparation Before Starting

When creating base characters, prioritize organizing stable information:

- Character name or alias.
- Identity, faction, profession, or functional positioning.
- Appearance and distinguishing features.
- Personality, goals, abilities, and weaknesses.
- Suitable genres or worlds for appearance.
- Hard facts that you do not want to be miswritten.

<Tip>
  Do not write temporary statuses from a specific chapter as permanent settings. For example, "injured," "on the run," or "just lost a companion" are more suitable to stay in the specific novel rather than the base Character Library.
</Tip>

## Recommended Usage Path

<Steps>
  <Step title="Open the Base Character Library">
    Find the "Base Character Library" (基础角色库) entry in the workbench navigation.
  </Step>
  <Step title="Create New or Precipitate Character">
    Create a new character, or precipitate a character from a novel character or book breakdown character.
  </Step>
  <Step title="Supplement Stable Settings">
    Fill in identity, appearance, personality, abilities, and usage boundaries. Upload or generate a character base image, and set the main image.
  </Step>
  <Step title="Import into a Novel">
    Import this character into a specific novel.
  </Step>
  <Step title="Adjust Novel Internal Character Status">
    After importing, adjust the novel internal character status according to the book's world and plot goals.
  </Step>
</Steps>

## How It Enters the Subsequent Creative Chain

The base Character Library provides reusable assets. After a character enters a specific novel, it becomes a character instance in that book, and continues to be influenced by the book's world, plot, chapter status, and relationship advancement.

This avoids two problems:

- Long-term settings in the Character Library being contaminated by a book's temporary plot.
- Character changes in one book automatically affecting other novels.

If you modify a character's current status in a novel, it does not equal automatically modifying the base Character Library. When you need to precipitate it as a long-term asset, you should explicitly save or sync it.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What is the difference between the base Character Library and characters in a novel">
    The base Character Library saves reusable character assets. Characters in a novel are the result of using this asset in the current story, and will carry the book's world, relationship progress, chapter status, and plot changes.
  </Accordion>

  <Accordion title="Will a character upgraded from book breakdown affect the original book breakdown">
    No. After upgrading, it becomes a new base character asset. Evidence, scenes, and images in the book breakdown archive remain in the book breakdown archive.
  </Accordion>

  <Accordion title="What is the use of a character main image">
    The main image is used to help you identify the character, and can also serve as a reference for subsequent visual generation. A character can have multiple candidate images, but it is recommended to choose the one that best matches the long-term setting as the main image.
  </Accordion>

  <Accordion title="What information is not suitable for the base Character Library">
    Temporary statuses that only belong to a book's current plot are not suitable for the base Character Library. For example, current chapter location, short-term injuries, recently occurred relationship conflicts, temporary disguises, etc.
  </Accordion>

  <Accordion title="Do characters still need to be changed after importing into a novel">
    Usually yes. Base characters are just the starting point. After importing, they should be adjusted according to the book's genre, world rules, main line goals, and character relationships to avoid characters feeling like imported templates.
  </Accordion>
</AccordionGroup>
