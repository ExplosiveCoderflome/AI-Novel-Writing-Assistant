The World Library is used to save reusable world-building samples. It is suitable for accumulating common world rules, factions, locations, relationship networks, and conflict structures, which can later be imported into specific novels and then adapted into a dedicated world for that book.

<Note>
  Content in the World Library is reusable assets, not the world currently in use by any specific novel. After importing into a novel, you can still modify it separately for the current work.
</Note>

## What the World Library Can Do for You

- Save reusable worlds, such as immortal sect worlds, future cities, post-apocalyptic bases, fictional dynasties, etc.
- Organize world handbooks, including core rules, major factions, story stages, and key tensions.
- Serve as a reference source when creating a new book, reducing the cost of building worlds from scratch.
- Save a mature world from a specific book back to the library for future reuse.
- Help you distinguish between "general world samples" and "the actual world used by the current novel."

## When to Use It

- You often write in the same type of world and want to accumulate a basic stage.
- A new book needs to reference an existing world, but you do not want to accidentally alter the original sample.
- You want to organize world rules first, then create different novels around it.
- A novel's world has matured, and you want to save it as a reference for future projects.
- You want to organize factions, locations, rules, and conflicts, rather than just writing a brief world introduction.

## Getting Started

<Steps>
  <Step title="Open the World Library">
    Find the "World Library" (世界样本库) entry in the workbench navigation, view existing world samples, or create a new world sample.
  </Step>
  <Step title="Organize the World Handbook">
    First write the world impression, core rules, major factions, story stage, and key tensions. Maps, faction diagrams, and other visual assets can be added later.
  </Step>
  <Step title="Import into a Novel">
    Import the world sample in the novel's basic information or the book's world entry to become a copy of the book's world.
  </Step>
  <Step title="Adjust as Needed">
    After importing, adjust the scope of use for the current novel around the protagonist and plot, so the world serves the story.
  </Step>
  <Step title="Save Back to the Library (Optional)">
    If the book's world develops more fully later, you can choose to save it back to the World Library for future project reuse.
  </Step>
</Steps>

## Recommended Understanding

| Asset Type | Purpose | Does Modification Affect Other Works |
| --- | --- | --- |
| World Library | Save general samples, suitable for long-term reuse | No |
| Book's World | The actual world copy used by a specific novel, adjusted for the protagonist and plot | Only affects the current novel |

Therefore, do not worry about having to follow the sample exactly after importing. After importing into a novel, you can still modify it separately for the current work.

## How It Enters the Subsequent Creative Chain

World samples first become a copy of a novel's book world before entering subsequent creation. The benefits of this approach are:

- The current novel can adjust the world according to its own protagonist and plot.
- The original world sample will not be contaminated by a book's temporary changes.
- Subsequent characters, planning, chapters, and covers can use the book's world information.
- If the book's world differs from the source sample, you can decide whether to sync it.

The World Library is more suitable for long-term asset management; what really affects writing in a specific novel is the book's world.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Will world samples directly affect all novels">
    No. World samples usually need to be imported into a novel first to become a copy of the book's world. Each novel can be adjusted separately on the copy.
  </Accordion>

  <Accordion title="Should I create a world sample first, or a novel first">
    If you already have a mature world, you can create a world sample first. If it is just a new idea, it is usually better to create a novel first, let the system generate a world based on the book's theme, and then consider saving it as a sample.
  </Accordion>

  <Accordion title="Can I still change it after importing a sample">
    Yes. The book's world after importing can be modified according to the current novel. Whether to sync the changes back to the sample should be decided manually by you.
  </Accordion>

  <Accordion title="How detailed should a world sample be">
    First write the parts that can support the story: core rules, major factions, key locations, conflict tensions, and taboo boundaries. Maps, faction diagrams, and other visual assets can be added later.
  </Accordion>

  <Accordion title="What is the difference between a world sample and a genre base">
    A genre base explains what type of work it is, while a world sample explains which stage the story takes place on. One genre can have multiple world samples, and the same world can serve different types of stories.
  </Accordion>
</AccordionGroup>
