This page lists the environment variables to know when running or deploying Biz Novel Studio from source. We recommend first reading the "Run from Source (Developers)" section in [Installation & Download](/en/installation).

## Configuration File Locations

- Server reads from `server/.env`
- Frontend reads from `client/.env` or `client/.env.local`
- The root `.env.example` is only an overview and cannot replace per-package configuration

Copy the example files and modify:

```bash
# macOS / Linux
cp server/.env.example server/.env
cp client/.env.example client/.env
```

```powershell
# Windows PowerShell
Copy-Item server/.env.example server/.env
Copy-Item client/.env.example client/.env
```

API keys and models can also be saved in system settings. Model routing is used to separately configure planning, body text, review, and book breakdown. For details, see [Model Configuration](/en/model-configuration).

## Server Configuration (server/.env)

### Basic Service

| Variable | Default / Example | Description |
| --- | --- | --- |
| `PORT` | `3000` | Server listening port |
| `DIRECTOR_NEXT_ENABLED` | `true` | Enables V1/V2 director selection; set to `false` to disable V2. Existing novels keep their original director version |
| `HOST` | `0.0.0.0` | Bind address. Change to `127.0.0.1` for public internet or server deployment |
| `ALLOW_LAN` | `true` | Whether to allow LAN access. Change to `false` for public deployment |
| `AI_NOVEL_ACCESS_TOKEN` | empty | Optional access token. Recommended for public internet or shared LAN |
| `CORS_ORIGIN` | `http://localhost:5173,...` | Cross-origin list; narrow to the actual domain for public deployment |
| `DATABASE_URL` | `file:./dev.db` (SQLite default) | Database connection string. Replace with the PostgreSQL connection string when using PostgreSQL |
| `API_JSON_LIMIT` | `20mb` | JSON request body size limit |
| `NOVEL_SNAPSHOT_RETENTION_COUNT` | `10` | Number of automatic version snapshots kept per novel; manual snapshots are not limited |

| `IMAGE_STORAGE_S3_ENDPOINT` | empty | MinIO/S3 endpoint address |
| `IMAGE_STORAGE_S3_REGION` | `us-east-1` | S3 region |
| `IMAGE_STORAGE_S3_BUCKET` | `ai-novel-images` | S3 bucket name |
| `IMAGE_STORAGE_S3_ACCESS_KEY_ID` | empty | S3 access key |

| `IMAGE_GENERATION_HTTP_TIMEOUT_MS` | `300000` | Maximum wait time for image generation API in milliseconds |

## Frontend Configuration (client/.env)

| Variable | Default / Example | Description |
| --- | --- | --- |
| `VITE_API_BASE_URL` | empty (inferred automatically in dev) | Only set when you need to pin the API address or deploy frontend and backend separately. Do not set it to `localhost` for LAN access, or the browser will request `localhost:3000` on the accessing device |
| `VITE_API_TIMEOUT_MS` | `600000` | API timeout in milliseconds, default 10 minutes |
| `VITE_MANUSCRIPT_REVISION_ENABLED` | disabled by default | Manuscript revision entry toggle. Enable when needed; not shown on mobile |

<Info>
  For the specific usage of `VITE_MANUSCRIPT_REVISION_ENABLED`, refer to the release notes and related Wiki notes in the source.
</Info>

<Warning>
  For public internet or server deployment, we recommend the following security adjustments:

  - Change `HOST` to `127.0.0.1`
  - Change `ALLOW_LAN` to `false`
  - Narrow `CORS_ORIGIN` to the actual domain
  - Narrow `API_JSON_LIMIT` (e.g., to `5mb`) to reduce large request body DoS attack surface
  - Enable `AI_NOVEL_ACCESS_TOKEN` access token protection
</Warning>

<Tip>
  In development, Vite's same-origin `/api` proxy reaches the server by default, so same-machine and LAN access usually do not need a `client/.env`. Only set `VITE_API_BASE_URL` when deploying frontend and backend separately or when pointing to another server address.
</Tip>
