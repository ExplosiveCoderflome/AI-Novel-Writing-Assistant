There are many proprietary terms in the workbench that may be confusing when first encountered. This glossary groups them by topic to help you quickly understand their meanings and usage scenarios.

## Director and Advancement

| Term | Meaning | See Also |
| --- | --- | --- |
| **Director V1** | The original director and novel workbench, retaining phase-by-phase creation entry points, suitable for continuing existing novels. | [Auto Director](/en/features/auto-director) |
| **Director V2** | The book director console, concentrating reading of directory, body text, and materials, continuously planning and generating by authorized scope. | [Auto Director](/en/features/auto-director) |
| **Book Director Console** | V2's centralized creation interface, where you can read body text, view materials, advance planning, and handle pause items. | [Quick Start](/en/quickstart) |
| **Fully Automatic Advancement** | The AI continuously completes planning, body text writing, checking, and saving within the authorized scope of this session, with ordinary phases automatically continuing. | [Auto Director](/en/features/auto-director) |
| **Phase-by-Phase Confirmation (Semi-Automatic)** | Saves results at phases requiring confirmation for your verification, then continues after verification, without needing to manually trigger each chapter. | [Auto Director](/en/features/auto-director) |
| **Authorized Scope** | The creation interval you explicitly submit to the AI, such as Chapters 1 to 3; after completion, you need to select the next segment. | [Auto Director](/en/features/auto-director) |
| **Pause** | The system actively stops due to external reasons, waiting for confirmation, or reaching a protection limit; progress is preserved. | [Auto Director](/en/features/auto-director) |
| **Failure** | The current command did not complete; you need to first look at the error information before deciding to retry or switch models. | [Run History](/en/features/task-center) |
| **Checkpoint** | A recoverable position saved by Auto Director; after pausing, you can resume from here without starting over. | [Auto Director](/en/features/auto-director) |
| **Director Follow-up** | A page for viewing pause reasons, phase results, and resume entry points, used to handle in-progress pause items. | [Auto Director](/en/features/auto-director) |
| **Run History (Task Center)** | Read-only list for viewing backend task queuing, running, failure, and recovery positions; real operations must be completed on the source page. | [Run History](/en/features/task-center) |
| **Direction Candidates** | Optional book-level directions and title sets generated by Auto Director based on ideas, for you to select and confirm. | [Auto Director](/en/features/auto-director) |
| **Book Contract** | A creative agreement writing target readers, selling points, promises, and hard constraints, providing a coordinate system for subsequent planning. | [Auto Director](/en/features/auto-director) |
| **Story Macro** | The long-term conflict, advancement cycle, and mainline structure of the entire book, helping maintain consistent direction throughout. | [Auto Director](/en/features/auto-director) |
| **Volume Strategy** | Volume strategy, goals, and advancement route; requires user confirmation. | [Auto Director](/en/features/auto-director) |
| **Volume Skeleton** | Volume list and tasks per volume, breaking the entire book into manageable chunks. | [Auto Director](/en/features/auto-director) |
| **Beat Board** | Breaks volume planning into executable beat nodes, connecting volume strategy with specific chapters. | [Auto Director](/en/features/auto-director) |
| **Chapter List** | Chapter titles, order, and basic goals; the last planning step before formally writing body text. | [Auto Director](/en/features/auto-director) |
| **Chapter Refinement / Brief** | Chapter brief, scene cards, and goals, providing specific execution instructions for body text generation. | [Auto Director](/en/features/auto-director) |
| **Quality Debt / Chapter Reminders** | Ordinary local quality issues recorded as reminders and advancement continues; not equivalent to global failure. | [Auto Director](/en/features/auto-director), [FAQ](/en/faq) |
| **Prioritize Completing the Whole Book** | Default strategy: records ordinary local issues as chapter reminders and continues writing subsequent chapters. | [FAQ](/en/faq) |
| **Quality First** | Stricter strategy: may pause after body text is saved, waiting for manual handling of quality issues. | [Auto Director](/en/features/auto-director) |

## Planning Structure

| Term | Meaning | See Also |
| --- | --- | --- |
| **Book Breakdown** | Breaks down reference works or your own drafts into evidence-based, structured creation materials, with 8 analysis subsections. | [Book Breakdown Workbench](/en/features/book-analysis) |
| **Write Following a Book** | Uses completed book breakdown results to start a book; can choose to continue the original work or reference it to create a new book. | [Novels & Starting a Book](/en/features/novels) |
| **Continue Original Work** | Retains original characters, world rules, timeline, and unresolved clues, continuing from the ending. | [Book Breakdown Workbench](/en/features/book-analysis) |
| **Reference to Create New Book** | Learns the structure, pacing, and writing style of the reference work, but generates new characters, world, and plot. | [Book Breakdown Workbench](/en/features/book-analysis) |
| **Creative Continuation Plan** | A bridge between book breakdown and the new project, providing the first three chapters' direction and this book's creative positioning. | [Book Breakdown Workbench](/en/features/book-analysis) |
| **Outline Workbench** | An independent creation tool: first organize ideas into an executable structure, confirm it, then hand it off as a novel. | [Outline Workbench](/en/features/outline-workbench) |
| **Outline Revision** | Every manual save or adoption of AI suggestions creates an independent, non-overwritable revision version. | [Outline Workbench](/en/features/outline-workbench) |
| **Foreshadowing Plan / Foreshadowing Ledger** | Foreshadowing in the outline first exists as a plan; only after evidence appears in the body text is it associated with the actual ledger. | [Outline Workbench](/en/features/outline-workbench) |

## Quality and Usage

| Term | Meaning | See Also |
| --- | --- | --- |
| **Single-Chapter Usage Protection** | V2 single-chapter default limit is 100,000 Tokens, accumulating generation, checking, text repair, and material organization calls for that chapter, preventing single-chapter consumption from spiraling out of control. | [AI Usage](/en/features/token-usage) |
| **Tokens** | The counting unit for AI calls; total Tokens = input + output; actual fees are based on the provider's bill. | [AI Usage](/en/features/token-usage) |
| **Cache Hit** | Providers charge a lower unit price for reused input prefixes; the workbench improves hit rate by stabilizing material prefixes. | [AI Usage](/en/features/token-usage) |

## Models and Configuration

| Term | Meaning | See Also |
| --- | --- | --- |
| **Model Routing** | Specifies which model to use for different tasks such as planning, body text, review, and book breakdown. | [Model Configuration](/en/model-configuration) |
| **Structured Output** | Planning steps require the model to return strict structured results; some reasoning models may be incompatible. | [Model Configuration](/en/model-configuration) |
| **Style Engine** | A long-term asset for saving, editing, and reusing narrative styles, keeping subsequent chapters in the same linguistic flavor. | [Style Engine](/en/features/style-engine) |
| **Anti-AI Rules** | Organizes undesired expression issues (templating, over-explaining, unnatural dialogue, etc.) into checkable rules. | [Anti-AI Rules](/en/features/anti-ai-rules) |

## Materials and Writing Style

| Term | Meaning | See Also |
| --- | --- | --- |
| **Knowledge Base / Vector Retrieval (Qdrant)** | A place to save long-term creation materials, recalling relevant fragments on demand during chapter execution through the RAG mechanism. | [Knowledge Base](/en/features/knowledge-base) |
| **World Library** | Saves reusable world view samples; after importing into a novel, they become this book's world copy and can be adjusted separately. | [World Library](/en/features/world-library) |
| **Basic Character Library** | Saves reusable character assets; after importing into a novel, they become character instances, with plot status maintained separately. | [Character Library](/en/features/character-library) |
| **Simple Creation** | Focuses on bookshelf, body text reading, and progress; suitable for letting Auto Director continuously complete the whole book. | [Novels & Starting a Book](/en/features/novels) |
| **Professional Creation** | Displays the complete chain including project settings, story macro, volume strategy, chapter breakdown, etc.; suitable for inspection and adjustment. | [Novels & Starting a Book](/en/features/novels) |
| **Creative Hub** | An entry point for status queries and problem diagnosis across the entire creation process; does not execute creation actions. | [Creative Hub](/en/features/creative-hub) |
| **Trending Genre Radar** | Extracts verifiable market signals from public rankings, providing genre and differentiation references for starting a book. | [Trending Genre Radar](/en/features/market-radar) |
| **Writing Kernel v2** | A new long-form body text process; currently still disabled by default in this version, can be enabled in settings. | [Changelog](/en/changelog) |
| **Original Draft Revision** | Supports adding, deactivating, merging chapters, and chapter-by-chapter modification; entry is disabled by default. | [Changelog](/en/changelog) |
