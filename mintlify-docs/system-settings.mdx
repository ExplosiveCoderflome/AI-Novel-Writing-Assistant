系统设置是管理创作环境全局配置的中心页面。左侧有七个分区：设置总览、模型与厂商、模型路由管理、自动导演、知识库与写法、桌面与维护、外观与主题。

新手先完成 **模型与厂商** 配置即可开始创作。其余分区都是增强或偏好项，可以以后按需调整。

<Info>
  设置只保存在当前设备，不影响已创建的小说内容和服务器数据。
</Info>

## 新手应该先配什么

| 分区 | 是否必须先配 | 建议 |
| --- | --- | --- |
| **模型与厂商** | 是 | 必须先添加至少一个可用文本模型，否则无法开始 AI 创作 |
| **模型路由管理** | 建议配 | 快捷配置后自动生效，后续想让不同任务用不同模型时再进来细调 |
| **外观与主题** | 否 | 按屏幕亮度和个人喜好调整界面配色和密度 |
| **自动导演** | 否 | 默认的「优先完成整本书」和 100,000 Tokens 单章上限适合大多数场景 |
| **知识库与写法** | 否 | 增强项，不影响开书和章节生产 |
| **桌面与维护** | 否 | 桌面版才需要关注 |

## 设置总览

打开系统设置时，默认进入设置总览。页面顶部是 **创作可用性检查**，回答「现在能不能开始创作、还差哪一步」。如果有未完成的必要配置，会提示具体缺失项。

下方是各分区的入口卡片，每张卡片显示当前摘要：

- **模型与厂商**：当前厂商和模型名称，或提示「尚未配置可用的文本模型」
- **模型路由管理**：已设置的任务路由条数
- **知识库与写法**：知识库是否开启、当前向量模型
- **桌面与维护**：桌面版显示「可检查桌面更新和本机旧数据」，网页端显示「无需桌面维护」
- **自动导演**：默认提示「设置确认偏好、问题处理和通知方式」

点击卡片上的「打开」按钮，即可进入对应分区。

## 模型与厂商

在这里添加并管理创作可用的模型厂商与模型，包括 API Key、API 地址、模型列表和输出上限。详细配置方法见 [模型配置](/model-configuration)。

同页还包含两项独立设置：

### 单次生成最长等待

控制世界观生成时等待模型返回的最长时间。本地模型较慢时可以调高，云端模型保持 2 分钟即可。页面会显示当前可设置范围。保存后，下一次世界观生成按这个时间等待；如果失败，系统可能再自动重试一次。

### AI 提示词与回答历史

勾选「保存提示词与回答」后，创作消息和模型回答会被保存下来。保存内容可在小说的「AI 用量与调用日志」中查看，可能包含完整正文，请按需开启。

启用后可设置两项参数：

- **保留天数**：1 到 365 天
- **压缩后容量上限**：1 到 4096 MB

系统每 15 分钟自动清理过期或超出容量的历史记录，优先删除最早的记录。关闭该功能后，系统停止保存新内容，但已保存的调用用量数据仍然保留。无论是否开启，耗时统计都会持续记录。

## 模型路由管理

为不同创作任务选择模型，并设置结构化输出的备用模型。路由健康时，自动导演和章节生产会按任务自动选择模型，不需要你每次手动指定。

例如，可以让规划步骤使用输出稳定的长上下文模型，正文生成使用文笔更好的模型，审阅修文使用性价比更高的模型。详细用法见 [模型配置](/model-configuration) 中的「模型路由」部分。

## 自动导演

设置问题处理、自动确认和创作提醒。每本书开始执行任务后，会按照当前的设置保留自己的执行规则，后续修改全局设置不会影响已经开始的任务。

### 单章 AI 用量上限

设置新任务每章的累计 AI 用量上限，默认 100,000 Tokens，可设置范围为 16,001 到 10,000,000。计算方式按未命中输入与输出累计，与模型单次最大输出不同。

任务开始后保留自己的额度设置。达到上限或剩余额度不足以进行下一步时，AI 会保存进度并询问是否追加预算。详见 [AI 用量与 Token 缓存](/features/token-usage)。

### 自动导演暂停提醒

自动导演等待确认、需要恢复或被校验拦住时，通过浏览器通知提醒你。只影响这台电脑上的当前浏览器，需要在浏览器中授权通知权限。如果被阻止，请在地址栏的权限设置中允许本网站发送通知。

### 问题处理规则

选择一套预设方案，或按问题逐项调整处理方式。

**两套预设方案**：

- **优先完成整本书**：局部问题处理一次后保留正文并继续，统一留到后续优化
- **质量优先**：局部问题处理一次后仍未解决会暂停，等待你确认后再继续

**单项问题可选动作**：

- 自动重试
- 记录提醒并继续
- 暂停等待处理
- 结束当前任务

问题按阶段分为规划、生成、质量、运行四类。可设置章节运行自动重试（不自动重试，或最多 1 次）。安全保护触发时系统仍会优先保护作品（暂停或结束任务）。保存后影响后续任务。

### 审批授权偏好

自动导演按范围执行时，会先带入这里的默认授权。未授权的审批点仍然会停下等你确认。

### 高级控制

默认折叠，展开后包含两项设置。

**待确认状态自动放行**：开启后，只处理生效基准时间之后产生、超过 14 天且没有命中未解决冲突的角色关系与信息认知提案，把它们提交为正史事实。系统不会自动撤销，如需回退需要依据留痕记录人工核对。存量提案不进入自动放行范围。开启需勾选风险说明并输入确认文本。

<Warning>
  自动放行会把符合条件的待确认提案直接提交为正史，建议仅在了解风险后开启。
</Warning>

**导演跟进通道配置**：通过钉钉、企业微信或飞书 / Lark 接收创作提醒，并继续或重试任务。飞书长连接适用于桌面端，无需公网回调地址。可填写站内访问地址，用于消息里的跳转链接，并选择要订阅的事件类型。

## 知识库与写法

这些增强项帮助 AI 理解你的参考资料和写法偏好，不影响你先开始创作。知识库检索未开启时，开书和章节生产仍然正常进行；知识库的具体检索配置在「知识库」页面维护，详见 [知识库](/features/knowledge-base)。

### 写法引擎运行设置

控制写法提取等待模型返回的最长时间，有三个预设档位：

| 档位 | 适用场景 |
| --- | --- |
| 快速检测 | 适合短文本或快速确认样本文风是否可提取 |
| 稳定推荐 | 适合大多数写法提取任务 |
| 长文提取 | 适合长篇原文或较慢模型 |

「高级设置」中可填写具体分钟数。保存后，新提交和重试的写法提取任务会使用该等待时间。

## 桌面与维护

桌面版可检查桌面更新和导入本机旧数据，这些操作不影响当前创作配置。网页端显示「无需桌面维护」，没有额外配置项。

## 外观与主题

按个人喜好调整界面显示，不影响小说内容和任务状态。

**显示模式**：跟随系统、浅色、深色。

**主题风格**：

- **墨砚**：克制的蓝灰色，适合日常创作
- **暖纸**：柔和的米白色，适合阅读和章节编辑
- **夜航**：深靛蓝与青绿色，适合 AI 执行和日志查看

**界面密度**：舒适、紧凑。

设置不满意时可点击「恢复默认主题」。主题只保存在当前设备。
