## 各平台安装步骤

<Tabs>
  <Tab title="Windows">
    **安装版**

    1. 双击 `setup-x64.exe`，按向导操作。可以自定义安装目录，默认创建桌面和开始菜单快捷方式。
    2. 如果出现「Windows 已保护你的电脑」提示，点 **更多信息 → 仍要运行**。
    3. 安装完成后会自动启动。

    **便携版**

    把 `portable-x64.exe` 放进一个单独的文件夹再运行。数据会保存在同目录下的 `<程序名>-data` 文件夹中，移动时连同这个文件夹一起复制。
  </Tab>
  <Tab title="macOS">
    1. 双击 `.dmg`，把 Biz Novel Studio 拖进「应用程序」。
    2. 首次打开如果被系统拦截，到 **系统设置 → 隐私与安全性**，在下方找到被阻止的应用，点 **仍要打开**。
    3. 如果提示「已损坏，无法打开」，在终端执行下面的命令后重新打开：

    ```bash
    xattr -dr com.apple.quarantine "/Applications/Biz Novel Studio.app"
    ```

    当前 Mac 安装包未做 Apple 签名与公证，所以首次打开需要手动放行。
  </Tab>
  <Tab title="Linux">
    ```bash
    chmod +x Biz-Novel-Studio-*-linux-x86_64.AppImage
    ./Biz-Novel-Studio-*-linux-x86_64.AppImage
    ```

    部分发行版运行 AppImage 需要先安装 FUSE（例如 Ubuntu 22.04 及以上安装 `libfuse2`）。
  </Tab>
</Tabs>

## 首次启动

桌面版启动时会先拉起本地服务，再进入工作台。启动页依次显示「启动本地引擎 → 加载工作区 → 已就绪」，通常几秒到十几秒。

进入工作台后，如果还没有可用的文本模型，会自动弹出 **快捷配置**。填好 API Key、地址和模型并通过检测后，就可以开始创作。详细流程见 [创作向导](/onboarding)。

<Warning>
  启动页停在「启动受阻」时，先点页面上的日志入口查看原因。常见原因是杀毒软件拦截了本地服务，或上一次进程没有完全退出。完全退出应用后重新打开，仍失败可保存日志包到 [Issues](https://github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant/issues) 反馈。
</Warning>

## 数据保存在哪里

小说、章节、设定、任务记录和本地数据库都保存在本机，不会上传到项目服务器（调用模型时，相关内容会发给你配置的模型供应商）。

| 版本 | 默认数据目录 |
| --- | --- |
| Windows 安装版 | `%LOCALAPPDATA%\AI-Novel-Writing-Assistant-v2` |
| Windows 便携版 | 程序所在目录下的 `<程序名>-data` |
| macOS | `~/Library/Application Support/AI-Novel-Writing-Assistant-v2` |
| Linux | `~/.AI-Novel-Writing-Assistant-v2` |

日志在数据目录下的 `logs` 文件夹。卸载 Windows 安装版**不会**删除数据目录，重装后数据仍在。

## 更新

| 版本 | 怎样更新 |
| --- | --- |
| Windows 安装版 | 启动时自动检查新版本。点顶部栏的版本号打开「版本与更新」，可以手动 **检查更新**，下载完成后点 **重启安装** |
| Windows 便携版 | 不支持应用内更新。下载新版便携包替换旧程序，保留 `-data` 文件夹 |
| macOS | 不支持应用内更新。下载新版 `.dmg` 覆盖安装，数据不受影响 |

## 备份与迁移

长篇创作的数据很重要，建议定期备份：

1. 完全退出应用（确认没有正在运行的生成任务）。
2. 复制整个数据目录到安全位置。
3. 重要作品另外导出一份正文。

迁移到新电脑时，在新电脑安装同一或更新版本，首次启动前把备份的数据目录放回对应位置即可。

<Warning>
  不要在应用运行时复制或替换数据库，也不要在没有备份的情况下删除数据目录。
</Warning>

## 源码运行（开发者）

环境要求：

| 项目 | 要求 |
| --- | --- |
| Node.js | `^20.19.0 \|\| ^22.12.0 \|\| >=24.0.0` |
| pnpm | `>=10.6.0`（仓库声明使用 `pnpm@10.6.0`） |
| 文本模型 | 至少一组可用 API 配置，可在启动后填写 |
| 数据库 | 默认本地 SQLite；可通过服务端配置使用 PostgreSQL |
| 知识库检索 | 可选 Qdrant 与 Embedding 模型，不是首次写作的前置条件 |

```bash
git clone https://github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant.git
cd AI-Novel-Writing-Assistant
pnpm install
cp server/.env.example server/.env   # Windows PowerShell 用 Copy-Item
pnpm dev
```

前端默认为 `http://localhost:5173`，服务端为 `http://localhost:3000`。`server/.env` 中确认 `DIRECTOR_NEXT_ENABLED=true`（开放 V2 选择）；尚未配置 Qdrant 时设置 `RAG_ENABLED=false` 先跑通创作。启动后打开系统设置，配置并测试模型（见 [模型配置](/model-configuration)）。

完整变量说明见 [环境变量](/developers/environment-variables)，目录结构与常用命令见 [架构与源码](/developers/architecture)。
