工作台中有不少专有名词，第一次遇到可能会困惑。这个术语表按主题分组，帮你快速搞懂它们的意思和使用场景。

## 导演与推进

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| **导演 V1** | 原导演与小说工作台，保留分阶段创作入口，适合继续原有小说。 | [自动导演](/features/auto-director) |
| **导演 V2** | 本书导演台，集中阅读目录、正文和资料，按授权范围连续规划和生成。 | [自动导演](/features/auto-director) |
| **本书导演台** | V2 的集中创作界面，可以阅读正文、查看资料、推进规划和处理暂停事项。 | [快速开始](/quickstart) |
| **全自动推进** | AI 在本次授权范围内连续完成规划、写正文、检查和保存，普通阶段自动继续。 | [自动导演](/features/auto-director) |
| **按阶段确认（半自动）** | 在需要确认的阶段保存结果等你核对，核对后继续，无需逐章手动触发。 | [自动导演](/features/auto-director) |
| **授权范围** | 你明确提交给 AI 的创作区间，如第 1 至 3 章，完成后需再选下一段。 | [自动导演](/features/auto-director) |
| **暂停** | 系统因外部原因、等待确认或达到保护上限而主动停下，进度保留。 | [自动导演](/features/auto-director) |
| **失败** | 当前命令没有完成，需要先看错误信息再决定重试或换模型。 | [运行记录](/features/task-center) |
| **检查点** | 自动导演保存的可恢复位置，暂停后可以从这里继续而不必从头开始。 | [自动导演](/features/auto-director) |
| **导演跟进** | 查看暂停原因、阶段结果和继续入口的页面，用于处理运行中的暂停事项。 | [自动导演](/features/auto-director) |
| **运行记录（任务中心）** | 只读列表，查看后台任务的排队、运行、失败和恢复位置，真正的操作需到来源页面完成。 | [运行记录](/features/task-center) |
| **方向候选** | 自动导演根据灵感生成的可选书级方向和标题组，由你选择确认。 | [自动导演](/features/auto-director) |
| **书契约** | 写入目标读者、卖点、承诺与硬约束的创作约定，为后续规划提供坐标系。 | [自动导演](/features/auto-director) |
| **故事宏观** | 整本书的长期冲突、推进循环和主线结构，帮助保持全书方向一致。 | [自动导演](/features/auto-director) |
| **卷战略** | 分卷策略、目标与推进路线，需要用户确认。 | [自动导演](/features/auto-director) |
| **卷骨架** | 卷列表与每卷任务，把整本书拆成可管理的大块。 | [自动导演](/features/auto-director) |
| **节奏板** | 将卷规划拆成可执行的节奏节点，连接卷战略与具体章节。 | [自动导演](/features/auto-director) |
| **章节清单** | 章节标题、顺序与基础目标，是正式写正文前的最后一道规划。 | [自动导演](/features/auto-director) |
| **章节细化 / 任务单** | 章节任务单、场景卡和目标，为正文生成提供具体的执行指令。 | [自动导演](/features/auto-director) |
| **质量债务 / 章节提醒** | 普通局部质量问题记录为提醒并继续推进，不等于全局失败。 | [自动导演](/features/auto-director)、[FAQ](/faq) |
| **优先完成整本书** | 默认策略，把普通局部问题记为章节提醒并继续写后续章节。 | [FAQ](/faq) |
| **质量优先** | 更严格的策略，正文保存后可能等待人工处理质量问题。 | [自动导演](/features/auto-director) |

## 规划结构

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| **拆书** | 把参考作品或自己的稿子拆成有证据、结构化的创作资料，共 8 个分析小节。 | [拆书工作台](/features/book-analysis) |
| **照着一本书写** | 用已完成的拆书结果开书，可选择续写原作或参考创作新书。 | [小说与开书](/features/novels) |
| **续写原作** | 保留原作角色、世界规则、时间线和未完线索，从结尾继续写。 | [拆书工作台](/features/book-analysis) |
| **参考创作新书** | 学习参考作品的结构、节奏和写法，但角色、世界和剧情重新生成。 | [拆书工作台](/features/book-analysis) |
| **创作承接方案** | 拆书和新项目之间的桥梁，提供前三章方向和本书创作定位。 | [拆书工作台](/features/book-analysis) |
| **大纲工作台** | 独立创作工具，先把想法整理成可执行的结构，确认后再交接为小说。 | [大纲工作台](/features/outline-workbench) |
| **大纲修订** | 每次手动保存或采纳 AI 建议都会创建独立且不可覆盖的修订版本。 | [大纲工作台](/features/outline-workbench) |
| **伏笔计划 / 伏笔台账** | 大纲中的伏笔先作为计划存在，正文出现证据后才关联实际台账。 | [大纲工作台](/features/outline-workbench) |

## 质量与用量

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| **单章用量保护** | V2 单章默认上限 100,000 Tokens，累计该章的生成、检查、修文与资料整理调用，防止单章消耗失控。 | [AI 用量](/features/token-usage) |
| **Tokens** | AI 调用的计数单位，总 Tokens = 输入 + 输出，实际费用以厂商账单为准。 | [AI 用量](/features/token-usage) |
| **缓存命中** | 厂商对重复使用的输入前缀收取较低单价，工作台通过稳定资料前置提升命中。 | [AI 用量](/features/token-usage) |

## 模型与配置

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| **模型路由** | 为规划、正文、审阅、拆书等不同任务分别指定使用哪个模型。 | [模型配置](/model-configuration) |
| **结构化输出** | 规划步骤需要模型返回严格的结构化结果，部分思考型模型可能不兼容。 | [模型配置](/model-configuration) |
| **写法引擎** | 保存、编辑和复用叙事风格的长期资产，让后续章节保持同一种语言味道。 | [写法引擎](/features/style-engine) |
| **反 AI 规则** | 把不希望的表达问题（模板感、过度解释、台词不自然等）整理成可检查的规则。 | [反 AI 规则](/features/anti-ai-rules) |

## 资料与写法

| 术语 | 含义 | 详见 |
| --- | --- | --- |
| **知识库 / 向量检索（Qdrant）** | 保存长期创作资料的地方，通过 RAG 机制在章节执行时按需召回相关片段。 | [知识库](/features/knowledge-base) |
| **世界样本库** | 保存可复用世界观样本，导入小说后成为本书世界副本，可单独调整。 | [世界样本库](/features/world-library) |
| **基础角色库** | 保存可复用角色资产，导入小说后成为角色实例，剧情状态单独维护。 | [角色库](/features/character-library) |
| **简易创作** | 以书架、正文阅读和进度为主，适合让自动导演持续完成整本书。 | [小说与开书](/features/novels) |
| **专业创作** | 展示项目设定、故事宏观、卷战略、拆章等完整链路，适合检查与调整。 | [小说与开书](/features/novels) |
| **创作中枢** | 面向整个创作过程的状态查询与问题诊断入口，不执行创作动作。 | [创作中枢](/features/creative-hub) |
| **热门题材雷达** | 从公开榜单提炼可核对的市场信号，为开书提供题材和差异化参考。 | [热门题材雷达](/features/market-radar) |
| **写作内核 v2** | 一种长篇正文新流程，当前版本仍默认关闭，可在设置中启用。 | [更新日志](/changelog) |
| **原稿修订** | 支持新增、停用、合并章节和逐章修改的能力，入口默认关闭。 | [更新日志](/changelog) |
