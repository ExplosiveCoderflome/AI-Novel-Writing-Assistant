这份路线图说明项目当前已经能帮助你完成什么、近期优先把哪些环节做稳，以及哪些能力仍处于后续评估阶段。完整的逐日变化见[更新日志](/changelog)和源仓库的[release-notes.md](https://github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant/blob/main/docs/releases/release-notes.md)。

## 当前可用的完整主链

截至 v0.8.1，项目的核心目标仍是帮助没有小说创作经验的用户，从一个方向走到可导出的完整正文。以下五条链路均已可用。

### 1. 找到开书方向

你可以按自己的准备程度选择入口：

| 入口 | 适合谁 | 状态 |
| --- | --- | --- |
| 从一个想法开始 | 只有初步灵感 | 已完成 |
| 从热门题材雷达开始 | 想参考市场信号 | 已完成 |
| 照着一本书写 | 已有拆书参考 | 已完成 |
| 手动创建 | 已准备好书名、简介和基础设定 | 已完成 |

相关说明：[热门题材雷达](/features/market-radar) · [拆书工作台](/features/book-analysis) · [小说与开书](/features/novels)

### 2. 由自动导演完成整书规划

自动导演可以连续推进项目设定、故事宏观规划、角色准备、卷战略、章节规划和正文生产。简易模式突出阅读、进度与继续创作，专业模式提供完整资料、章节控制、审校、恢复和导出入口。

v0.8.0 起新增独立大纲工作台，支持建立大纲项目、导入 Markdown 或 TXT、编辑修订、查看历史，并按已采用的大纲开书。未绑定大纲的全自动写作路径保持不变。

相关说明：[自动导演](/features/auto-director) · [大纲工作台](/features/outline-workbench) · [导演跟进](/features/director-follow-up)

### 3. 按章节持续生成、检查和保存

每章会经过执行合同准备、正文生成、接收检查、必要修复和保存。旧项目缺少章节目标、任务单或场景边界时，系统会先补齐当前章的执行合同，再继续写作，避免整本任务反复卡在同一检查点。

局部质量问题默认作为可见的质量债务留在章节层处理，不会自动阻断整本生产；只有明确需要重规划、正文无法安全保存、运行安全风险，或所选规则要求人工确认时，任务才会停在已保存的章节边界。

相关说明：[章节执行链](/guides/chapter-execution) · [按阶段恢复](/guides/recovery-by-phase)

### 4. 管理写法、知识与创作资产

拆书结果、知识库、世界与角色状态、提示词模板都会参与后续生成。正文提示词支持在"正文效果实验室"中选择模型测试当前草稿，测试结果不会直接覆盖已经保存的章节。

相关说明：[提示词管理](/features/prompt-management) · [知识库](/features/knowledge-base) · [世界图书馆](/features/world-library) · [角色库](/features/character-library)

### 5. 恢复长任务并导出成果

运行记录会保留自动导演、拆书、批量生成等长任务的阶段和错误原因。模型余额或配额不足、质量优先规则要求确认时，任务会保留已完成正文与恢复位置；处理模型配置或确认问题后，可以从未完成章节继续。专业创作支持按章节顺序导出整本 TXT 正文，项目资产仍可使用 Markdown 或 JSON 导出。

相关说明：[任务中心](/features/task-center) · [系统设置](/system-settings)

## 当前开发重点

近期开发遵循以下优先顺序：

<Steps>
  <Step title="稳定自动导演恢复与章节生产链">
    让暂停、重试、恢复和重规划共享清晰的状态边界，优先保护已经保存的正文。
  </Step>
  <Step title="提高新手完成整本书的成功率">
    给出明确默认值、推荐入口和下一步操作，减少要求用户自行修复结构、节奏或角色弧线。
  </Step>
  <Step title="统一运行时、提示词与任务投影契约">
    先解决后端实际状态、运行记录和前端展示不一致的问题，再增加新的工作流分支。
  </Step>
  <Step title="控制创作入口复杂度">
    市场雷达、拆书、创作中枢和自动导演都服务于小说完成主链，不把创作中枢扩展成与成书无关的通用聊天工具。
  </Step>
</Steps>

## 后续评估方向

这些方向具有长期价值，但不会优先于主链稳定性：

| 方向 | 说明 | 状态 |
| --- | --- | --- |
| 长程上下文记忆 | 让世界规则、角色状态、时间线、伏笔和写法在长篇后段仍能稳定参与生成 | 计划中 |
| 跨书资产复用 | 复用题材基底、推进模式、世界样本、角色档案和写法资产，同时保留来源与适用边界 | 计划中 |
| 质量报告与集中返修 | 把章节级质量债务汇总成可理解、可分批处理的整书报告 | 计划中 |
| 叙事引擎工作台 | 把世界、角色、势力、资源和事件做成可观察、可推演的创作资产，但必须降低而不是增加新手负担 | 计划中 |
| 视觉改编产线 | 在小说主链稳定后继续完善漫画、漫剧和短剧的角色一致性、镜头连贯与成片导出 | 进行中 |
| 桌面版安装与自助运维 | 继续简化模型供应商配置、本地知识库存储和常见错误恢复 | 进行中 |

<Info>
  写作内核 v2 仍默认关闭。大纲反馈、更完整的原稿修订后续能力、短篇适配与创作承接合同不在当前版本。
</Info>
