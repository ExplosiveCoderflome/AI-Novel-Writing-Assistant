**Biz Novel Studio** 是一款开源的 AI 小说创作工作台。你只需要先有一个想法，工作台会帮你把方向、人物、世界和章节接起来：AI 帮你规划世界与角色、逐章写作、检查和保存，让长篇创作有一条可以继续走下去的路。

长篇由自动导演持续推进，短篇走独立的完整成稿流程。它面向第一次写小说的人，也为需要维护长期资料、研究 AI 创作流程的作者与开发者提供更细的工具。

**桌面版适合直接开始写作；源码版适合开发和自行部署。** 模型需要使用你自己的 API 配置，知识库检索可按需启用。

## 现在已经能做什么

<CardGroup cols={2}>
  <Card title="把点子变成一本书" icon="compass" href="/features/novels">
    自动导演整理题材、卖点、人物目标和候选方向；也可从热门题材或完成的拆书起步。
  </Card>

  <Card title="写一篇完整短篇" icon="feather" href="/features/short-story">
    从想法与方向选择进入 3,000—30,000 字短篇生产，连续阅读、修改和导出。
  </Card>

  <Card title="持续写出后续章节" icon="book-open" href="/features/auto-director">
    V2 导演围绕授权范围推进近期规划、章节任务、场景、正文、检查与保存；V1 保留原工作流程。
  </Card>

  <Card title="维护世界与人物" icon="users" href="/features/world-library">
    保存本书世界、角色、关系和章节状态，查看世界地图与角色关系图，为后续创作提供资料。
  </Card>

  <Card title="拆书学习参考作品" icon="scissors" href="/features/book-analysis">
    拆书分析结构、人物与写法，回溯原文证据；结果可用于知识库、写法资产或参考开书。
  </Card>

  <Card title="为不同任务选模型" icon="route" href="/model-configuration">
    在页面配置供应商、连接测试与模型路由，为规划、正文、审阅、拆书分别选择模型。
  </Card>
</CardGroup>
