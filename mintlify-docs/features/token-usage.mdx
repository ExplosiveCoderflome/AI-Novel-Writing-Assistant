AI 用量与 Token 缓存是理解创作成本和优化调用效率的重要模块。工作台在写作过程中会详细记录每次 AI 调用的消耗，并通过缓存机制减少重复成本。

<Info>
  用量页覆盖已记录的调用；未记录的旧历史不会被估算补齐。实际费用以厂商账单为准。
</Info>

## AI 用量怎么看

在 V2 本书顶部或书架打开 **「AI 用量」**，可以查看和筛选调用记录。

### 查看维度

| 筛选维度 | 说明 |
| --- | --- |
| 全书总计 | 整本小说已记录的输入与输出 Tokens |
| 章节 | 按章节查看该章累计消耗 |
| 步骤 | 规划、正文、审阅、修文等不同阶段的消耗 |
| 厂商 | 按供应商分组，适合多厂商配置时核对 |
| 模型 | 不同模型在各步骤的消耗对比 |
| 状态 | 成功、失败或重试的调用统计 |

### 理解总 Tokens

**总 Tokens = 输入 Tokens + 输出 Tokens。** 缓存命中与未命中都属于输入，不要再加一次。

规划、正文、审阅和修文都可能产生消耗，不能只按最终正文长度判断费用。

## Token 缓存与调用优化

长篇创作会反复使用本书约定、写法与世界规则。工作台把可复用的规则和书级、卷级资料放在输入前部，再附上本章任务、当前状态与正文，为模型供应商复用相同前缀提供条件。

### 哪些部分做了优化

- **稳定资料前置**：表达规则、作品约定和适用的世界规则按复用范围组织；每次读取当前资料，修改设置后后续调用使用新内容。
- **同章修文复用前缀**：局部修文把本次修复重点放在同章资料和正文之后，资料与正文未变化时更容易复用前缀。
- **有效审校结果复用**：正文、创作约定、检查规则、模型与参数等相关条件一致时，复用有效的检查结果，减少重复调用。
- **减少无效修文与复验**：检查区分必须修复的缺口和普通表达建议，残余局部问题保留为质量提醒，避免反复改整章。

### 不同步骤的复用空间

| 步骤 | 可以复用的主要资料 | 必须随创作更新的内容 |
| --- | --- | --- |
| 章节规划 | 书级定位、作品约定、适用的卷级目标 | 本章任务、近期结果、人物状态 |
| 正文生成 | 写法与表达规则、作品约定、适用的世界规则 | 上章接续、本章事件、场景和人物状态 |
| 章节检查 | 检查标准、同章任务与约定 | 当前待检查正文与修文结果 |
| 局部修文 | 本书写法、同章资料、未变化的正文 | 本次问题证据、修复重点和追加要求 |
| 写后资料整理 | 抽取规则、确实未变化的相关资料 | 新正文、角色变化、资源与伏笔状态 |

正文需要输入新的剧情和状态，这部分未命中是正常成本。首次调用、切换模型或通道、修改书级资料，也可能让命中量发生变化。

### 查看实际效果

在本书「AI 用量」中筛选同一章节、步骤与模型，比较连续调用的输入、输出、命中和未命中 Tokens。也可以在 **AI 实况** 中查看正在执行的调用。

缓存统计以厂商实际返回为准；未提供的字段显示「未知」。实际费用以厂商账单为准。

## 单章用量保护

V2 单章默认用量保护上限为 **100,000 Tokens**，累计包含该章的生成、检查、修文与资料整理调用。

### 计算方式

- **新章节**：按输入扣除供应商已报告的缓存命中后，加输出计数。
- **历史章节**：保留原计量方式。

达到上限时，系统会在本书导演台暂停并展示原因，你可以按建议额度或自定额度继续本章；正文、累计用量和恢复位置都会保留。

export const TokenUsageCalculator = () => {
  const LIMIT = 100000;
  const [inputTokens, setInputTokens] = useState(40000);
  const [cacheHitTokens, setCacheHitTokens] = useState(20000);
  const [outputTokens, setOutputTokens] = useState(15000);

  const effectiveInput = Math.max(0, inputTokens - cacheHitTokens);
  const totalCharge = effectiveInput + outputTokens;
  const ratio = Math.min(totalCharge / LIMIT, 1);
  const overLimit = totalCharge > LIMIT;

  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, padding: 20, fontFamily: "inherit" }}>
      <style>{`
        .tu-row { display: flex; align-items: center; gap: 12px; margin: 10px 0; }
        .tu-label { width: 130px; font-size: 13px; fontWeight: 600; color: inherit; flex-shrink: 0; }
        .tu-value { min-width: 60px; font-size: 14px; font-weight: 600; text-align: right; }
        .tu-slider { flex: 1; }
        .tu-bar-bg { height: 14px; border-radius: 7px; background: rgba(127,127,127,.15); overflow: hidden; }
        .tu-bar-fill { height: 100%; border-radius: 7px; transition: width 0.5s ease, background 0.5s ease; }
      `}</style>

      <div className="tu-row">
        <span className="tu-label">输入 Tokens</span>
        <input
          type="range"
          min={0}
          max={120000}
          step={1000}
          value={inputTokens}
          onChange={(e) => setInputTokens(Number(e.target.value))}
          className="tu-slider"
        />
        <span className="tu-value">{inputTokens.toLocaleString()}</span>
      </div>
      <div style={{ fontSize: 12, opacity: 0.7, marginTop: -6, marginBottom: 6, marginLeft: 142 }}>
        包含缓存命中与未命中的全部输入
      </div>

      <div className="tu-row">
        <span className="tu-label">缓存命中 Tokens</span>
        <input
          type="range"
          min={0}
          max={inputTokens}
          step={1000}
          value={cacheHitTokens}
          onChange={(e) => setCacheHitTokens(Number(e.target.value))}
          className="tu-slider"
        />
        <span className="tu-value">{cacheHitTokens.toLocaleString()}</span>
      </div>
      <div style={{ fontSize: 12, opacity: 0.7, marginTop: -6, marginBottom: 6, marginLeft: 142 }}>
        供应商已报告的缓存命中部分
      </div>

      <div className="tu-row">
        <span className="tu-label">输出 Tokens</span>
        <input
          type="range"
          min={0}
          max={60000}
          step={1000}
          value={outputTokens}
          onChange={(e) => setOutputTokens(Number(e.target.value))}
          className="tu-slider"
        />
        <span className="tu-value">{outputTokens.toLocaleString()}</span>
      </div>

      <div style={{ display: "flex", gap: 16, marginTop: 16, padding: 14, borderRadius: 10, background: "rgba(127,127,127,.08)", border: "1px solid rgba(127,127,127,.2)" }}>
        <div style={{ flex: 1 }}>
          <div style={{ fontSize: 12, opacity: 0.7 }}>计费 Tokens（输入扣命中 + 输出）</div>
          <div style={{ fontSize: 22, fontWeight: 700, color: overLimit ? "#EF4444" : "#16A34A", marginTop: 4 }}>
            {totalCharge.toLocaleString()}
          </div>
        </div>
        <div style={{ flex: 1 }}>
          <div style={{ fontSize: 12, opacity: 0.7 }}>占默认上限（{LIMIT.toLocaleString()}）</div>
          <div style={{ fontSize: 22, fontWeight: 700, marginTop: 4, color: overLimit ? "#EF4444" : "inherit" }}>
            {(ratio * 100).toFixed(1)}%
          </div>
        </div>
      </div>

      <div style={{ marginTop: 12 }}>
        <div className="tu-bar-bg">
          <div
            className="tu-bar-fill"
            style={{
              width: `${ratio * 100}%`,
              background: overLimit ? "#EF4444" : "#16A34A",
            }}
          />
        </div>
      </div>

      {overLimit && (
        <div style={{ marginTop: 12, padding: 10, borderRadius: 8, background: "rgba(239,68,68,.12)", border: "1px solid rgba(239,68,68,.4)", color: "#EF4444", fontSize: 13, fontWeight: 600 }}>
          已超过默认上限 {LIMIT.toLocaleString()} Tokens。达到上限时系统会在本书导演台暂停，可按建议或自定额度继续。
        </div>
      )}

      <div style={{ fontSize: 12, opacity: 0.7, marginTop: 10 }}>
        规则说明：新章节按输入扣除供应商已报告的缓存命中后加输出计数；历史章节保留原计量方式。
      </div>
    </div>
  );
};
