# AI-Novel-Writing-Assistant

一款开源的 AI 小说写作助手。「AI 导演」先规划整本书——世界设定、人物、大纲与章节列表——再调用大语言模型逐章生成正文，全程可干预、可续写。

- **自动导演开书**：从一句话创意到完整长篇，规划与生成一体化
- **多模型支持**：兼容主流大模型与本地模型（Ollama / LM Studio）
- **桌面端 + Web**：提供 Windows / macOS / Linux 桌面安装包

本项目采用 GNU AGPL-3.0 开源协议，源码见 [GitHub 仓库](https://github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant)。
